## 1 Dijkstra’s Algorithm

现在我们将使用迪杰斯特拉算法来解决边权非负的图中的单源最短路径问题. 迪杰斯特拉算法的关键思想是，作为一个不变量，对于所有 $t \in V$，算法会维护一个对从源点 $s$ 到 $t$ 的距离的估计 $d[t]$，使得：
1. 在任何时刻，$d[t] \geq d(s, t)$. 
2. 当对 $t$ 的计算完成时，$d[t]=d(s, t)$. 

**算法1：迪杰斯特拉算法 $(G = (V, E), s)$**
- 对于所有 $t \in V$：将 $d[t]$ 设为 $\infty$ // 设置初始距离估计值
- $d[s] \leftarrow 0$
- $F \leftarrow \{v | v \in V\}$ // $F$ 是尚未获得最终距离估计值的节点集合
- $D \leftarrow \varnothing$ // $D$ 是已获得最终距离估计值的节点集合
- 当 $F \neq \varnothing$ 时执行以下操作：
    - $x \leftarrow$ $F$ 中具有最小距离估计值的元素
    - 对于 $(x, y) \in E$ 执行：
        - $d[y] \leftarrow \min(d[y], d[x] + w(x, y))$ // “松弛” $y$ 的估计值
        - // 对于最短路径：如果 $d[y]$ 发生变化，则 $\pi(y) \leftarrow x$
    - $F \leftarrow F \setminus \{x\}$
    - $D \leftarrow D \cup \{x\}$

我们将证明迪杰斯特拉算法能够正确计算从 $s$ 到所有 $t \in V$ 的距离. 

**命题1**：对于所有 $u$，在任何时刻都有 $d[u] \geq d(s, u)$. 

这个命题的正式证明通过归纳法进行. 特别地，要证明在任何时刻，如果 $d[u] < \infty$，那么 $d[u]$ 就是从 $s$ 到 $t$ 的某条路径的权重. 因此在任何时刻，$d[u]$ 至少是最短路径的权重，从而 $d[u] \geq d(s, u)$. 
作为基础情况，我们知道初始时 $d[s]=0 = d(s, s)$，而所有其他距离估计值都是 $\infty$，所以我们知道基础情况成立. 现在，假设 $d[u]$ 已被更新为 $d[x]+w(x, u)$（根据归纳假设，存在一条从 $s$ 到 $x$ 的权重为 $d[x]$ 的路径，以及一条权重为 $w(x, u)$ 的边 $(x, u)$）. 这意味着存在一条从 $s$ 到 $u$ 的权重为 $d[x]+w(x, u)$ 的路径. 这就意味着 $d[u]$ 至少是最短路径的权重，归纳论证完成. 

**命题2**：当节点 $x$ 被放入 $D$ 中时，$d[x]=d(s, x)$. 

注意到证明上述命题对于证明算法的正确性是足够的，因为 $d[x]$ 一旦被放入 $D$ 中就永远不会改变，因为它只能在 $d[y]+w(y, x) < d[x]$ 时被改变，但对于所有 $y \in F$ 都有 $d[x] \leq d[y]$ 且 $w(y, x) \geq 0$（所有边权都是非负的）. 
对于所有 $y \in F$，在 $x$ 被插入到 $D$ 之后该断言仍然成立这一假设产生矛盾：假设在某个点对于某个 $y \in F$ 有 $d[y] < d[x]$，令 $y$ 是第一个这样的节点. 在 $d[y]$ 被更新为 $d[y'] + w(y', y)$（对于所有 $y' \in F$）之前，由于 $y'$ 是 $y$ 的某个邻居节点，并且所有边权都是非负的，我们得到了一个矛盾. 
我们通过归纳证明节点放入 $D$ 的顺序. 对于基础情况，$s$ 被放入 $D$ 中，此时 $d[s]=d(s, s)=0$，所以初始时，该命题成立. 

对于归纳步骤，我们假设对于当前在 $D$ 中的所有节点 $y$，都有 $d[y]=d(s, y)$. 令 $x$ 是当前在 $F$ 中具有最小距离估计值的节点（这个节点即将从 $F$ 移动到 $D$ 中）. 我们将证明 $d[x]=d(s, x)$，这将完成归纳. 
令 $p$ 是一条从 $s$ 到 $x$ 的最短路径，假设 $z$ 是 $p$ 上最接近 $x$ 且满足 $d[z]=d(s, z)$ 的节点. 我们知道这样的节点 $z$ 存在，因为至少有一个节点 $s$ 满足 $d[s]=d(s, s)$. 根据 $z$ 的选择，对于 $p$ 上 $z$ 和 $x$ 之间（不包括 $z$）的每个节点 $y$，都有 $d[y]>d(s, y)$. 考虑以下情况：
1. 如果 $z = x$，那么 $d[x]=d(s, x)$，我们就完成了证明. 
2. 假设 $z \neq x$. 那么存在一个节点 $z'$ 在 $p$ 上紧跟在 $z$ 之后（这里可能 $z' = x$）. 我们知道 $d[z'] = d(s, z') \leq d(s, x) \leq d[x]$. 从 $s$ 到 $z'$ 的最短路径是 $p$ 从 $s$ 到 $z'$ 的前缀，因为 $p$ 是最短路径，并且边上的权重是非负的，所以 $p$ 从 $s$ 到 $x$ 的这部分权重是非负的. 另外，我们有 $d(s, z) \leq d(s, x)$. 从 $z$ 到 $z'$ 的边权重非负，前面的不等式等价于 $d[z'] = d(s, z')$，这就证明了该命题. 
最后，假设 $d[z'] < d[x]$. 根据 $x \in F$ 的选择，我们知道 $d[x]$ 是 $F$ 中最小的距离估计值. 所以，由于 $d[z'] < d[x]$，我们知道 $z' \in F$ 且必须在 $x$ 之前被放入 $D$ 中. 这意味着 $d[z'] = d(s, z') + w(z', z) = d(s, z')$，因为 $z'$ 在从 $s$ 到 $x$ 的最短路径上，并且距离估计值的更新是正确的. 但是这与 $x$ 是 $p$ 上最接近 $x$ 且满足 $d[z]=d(s, z)$ 的节点这一事实相矛盾. 因此，我们最初假设 $d[z'] < d[x]$ 一定是错误的，所以 $d[x]=d(s, x)$.
