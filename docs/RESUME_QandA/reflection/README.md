### 项目介绍

- 我们这个医疗套电客服是一个动作驱动型的：

    访客在系统搜索框输入症状后，小模型进行疾病诊断并记录线索。中控系统结合预设工作流和动作识别模型双重机制，智能判断当前应执行"问诊"、"答疑"还是"套电"，然后下发动作指令，一级动作指令有问诊/答疑/套电；二级动作指令有，以问诊为例，有问年龄/问检查情况等。模型根据指令和线索生成话术，中控进行去重过滤避免重复提问。整个流程具备闭环反馈：套电成功则结束对话，失败则继续问诊收集信息，循环往复直到成功获取联系方式。

- 遇到的问题
    - **问题一：医院话术偏好难以满足**。不同医院对相同疾病有不同的问诊偏好和话术要求。典型案例是语言发育迟缓的问诊场景：当小孩迟迟不说话时，我们用历史对话让Qwen生成微调数据，模型容易容易往自闭症方向深挖，询问社交障碍、刻板行为等问题。但医院认为这种问法过于敏感和夸张，更希望优先从生理因素（如舌系带过短）或环境因素（如家庭语言氛围不足）入手。这种医院特定的话术偏好需要通过偏好数据集来微调模型。然而构造偏好数据的难点在于：如何从海量对话中精准定位符合特定疾病、特定动作的高质量话术？我们的解决方案是建立一套**离线数据筛选机制**：首先训练**疾病识别模型**（判断对话涉及哪种疾病）和**话术动作识别模型**（判断每轮对话是问诊、答疑还是套电），利用这两个模型对线上历史对话进行双重过滤，筛选出符合目标疾病和目标动作的对话片段。然后将这些筛选后的对话输入72B大模型，让它生成符合医院偏好要求的标准回复，最终用这些数据进行偏好微调，使模型的话术风格更贴合医院实际需求。
    - **问题二：多轮问诊的核心疾病维度覆盖率过低**。智能客服在多轮对话中容易陷入单一疾病维度的反复追问，无法全面覆盖该疾病的关键诊断维度。典型表现是性早熟案例：模型在问完访客身高后，会持续深挖身高相关问题（最近长高了多少、饮食习惯如何、作息规律吗），但却忽略了性早熟诊断中更关键的维度——生殖器发育情况、情绪变化等。这种问诊模式会导致"问了很多但没问到点上"，影响后续医生诊断的准确性。问题根源可能是上下文过长导致模型对前面的历史对话感知能力下降，无法记住已经问过哪些维度、还有哪些重要维度未覆盖。为解决这个问题，我们采用了**图谱检索增强生成方法**：首先人工筛选和审核高质量的历史对话数据，这些对话代表了针对某种疾病的标准问诊流程，符合医院的诊断要求。然后将这些对话的每个句子作为图谱节点，并为每个节点打上双重标签——**疾病标签**（如"性早熟""语言发育迟缓"）和**意图标签**（如"问身高""问月经""问生殖器发育"），这个意图标签类似于之前提到的二级动作指令。同一段历史对话中前后相邻的句子通过边连接，形成问诊的逻辑流程图。当新的实时对话进行到一定轮次后，系统会对访客的历史对话进行疾病诊断，同时对前一轮机器人的话术进行意图识别，得到当前的"疾病+意图"组合。然后拿着这个组合去Neo4j图谱中检索：找到匹配该疾病和该意图的节点，以及这些节点通过边连接的后续节点（代表下一步应该问什么）。将检索到的这些句子作为参考示例，输入到生成模型中进行检索增强生成，引导模型从当前维度跳转到其他重要但尚未覆盖的维度。这种方法相当于给模型提供了"专家级的问诊路线图"，让它知道问完身高后应该转向问生殖器和情绪，而不是继续纠缠在饮食作息等次要问题上。实验结果显示，这种图谱检索增强方法使得后续问诊的核心疾病维度覆盖率得到显著提升，确保重要诊断信息不会遗漏。
