## 爬楼梯

> 方案i和方案i-j有关

1. 假设你正在爬楼梯. 需要 n 阶你才能到达楼顶. 每次你可以爬 1 或 2 个台阶. 你有多少种不同的方法可以爬到楼顶呢？

    dp[i] 表示到达第 i 阶楼梯的不同方法数

    ```python
    dp[0] = 1
    dp[1] = 1
    # i>=2
    dp[i] = dp[i-1]+dp[i-2]
    ```

2. 给你一个整数数组 cost ，其中 cost[i] 是从楼梯第 i 个台阶向上爬需要支付的费用. 一旦你支付此费用，即可选择向上爬一个或者两个台阶. 你可以选择从下标为 0 或下标为 1 的台阶开始爬楼梯. 请你计算并返回达到楼梯顶部的最低花费. 

    dp[i] 表示到达第 i 个台阶的最低花费

    ```python
    dp[0] = cost[0]
    dp[1] = cost[1]
    # i>=2
    dp[i] = min(dp[i-1],dp[i-2])+cost[i]

    ```

3. 给你一个由不同整数组成的数组 nums ，和一个目标整数 target . 请你从 nums 中找出并返回总和为 target 的元素组合的个数. 1 <= nums[i] <= 1000. nums 中的所有元素 互不相同

    dp[i] 表示总和为 i 的元素组合的个数

    ```python
    dp[0] = 1
    # i>=1
    for num in nums:
        if num<=i:
            dp[i] += dp[i-num]

    ```

在问题一中，通过不断累加前两个台阶的方法数来得到当前台阶的方法数；在问题二中，通过取前两个台阶的最小花费数来得到当前台阶的最小花费；问题三中则是通过不断累加由不同元素组合得到的和为 i - num 的组合数来得到和为 i 的组合数. 问题一、问题二的台阶数是连续的，而问题三中的数字组合是离散的，来自给定的数组 nums.

## 网格图DP

> 数组的索引通常对应于网格中的位置，数组的值代表了与该位置相关的某种最优解或计数

1. 给定一个包含非负整数的 m x n 网格 grid ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小. 说明：每次只能向下或者向右移动一步. 

    - 状态定义：设 dp[i][j] 表示从左上角 (0, 0) 到位置 (i, j) 的最小路径和. 
    - 状态转移方程：因为每次只能向下或向右移动一步，所以 dp[i][j] = min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j]（当 i > 0 且 j > 0 时）. 对于边界情况，当 i == 0 且 j > 0 时，dp[0][j] = dp[0][j - 1] + grid[0][j]；当 j == 0 且 i > 0 时，dp[i][0] = dp[i - 1][0] + grid[i][0]；当 i == 0 且 j == 0 时，dp[0][0] = grid[0][0]. 
    - 最终结果：dp[m - 1][n - 1] 即为从左上角到右下角的最小路径和. 

2. 一个机器人位于一个 m x n 网格的左上角. 机器人每次只能向下或者向右移动一步. 机器人试图达到网格的右下角. 问总共有多少条不同的路径？

    - 状态定义：设 dp[i][j] 表示从左上角 (0, 0) 到位置 (i, j) 的不同路径数量. 
    - 状态转移方程：因为每次只能向下或向右移动一步，所以 dp[i][j] = dp[i - 1][j] + dp[i][j - 1]（当 i > 0 且 j > 0 时）. 对于边界情况，当 i == 0 且 j > 0 时，dp[0][j] = 1；当 j == 0 且 i > 0 时，dp[i][0] = 1；当 i == 0 且 j == 0 时，dp[0][0] = 1. 
    - 最终结果：dp[m - 1][n - 1] 即为从左上角到右下角的不同路径数量. 

3. 给定一个 m x n 的整数数组 grid. 一个机器人初始位于 左上角（即 grid[0][0]）. 机器人尝试移动到 右下角（即 grid[m - 1][n - 1]）. 机器人每次只能向下或者向右移动一步. 网格中的障碍物和空位置分别用 1 和 0 来表示. 机器人的移动路径中不能包含 任何 有障碍物的方格. 返回机器人能够到达右下角的不同路径数量. 

    - 状态定义：设 dp[i][j] 表示从左上角 (0, 0) 到位置 (i, j) 的不同路径数量，其中 grid[i][j] == 0 表示该位置为空，grid[i][j] == 1 表示该位置有障碍物. 
    - 状态转移方程：如果 grid[i][j] == 1，则 dp[i][j] = 0；否则，dp[i][j] = dp[i - 1][j] + dp[i][j - 1]（当 i > 0 且 j > 0 时）. 对于边界情况，当 i == 0 且 j > 0 时，如果 grid[0][j] == 0，dp[0][j] = dp[0][j - 1]，否则 dp[0][j] = 0；当 j == 0 且 i > 0 时，如果 grid[i][0] == 0，dp[i][0] = dp[i - 1][0]，否则 dp[i][0] = 0；当 i == 0 且 j == 0 时，如果 grid[0][0] == 0，dp[0][0] = 1，否则 dp[0][0] = 0. 
    - 最终结果：dp[m - 1][n - 1] 即为从左上角到右下角的不同路径数量. 

4. 给你一个大小为 m x n 的二维整数数组 grid 和一个整数 k . 你的任务是统计满足以下 条件 且从左上格子 (0, 0) 出发到达右下格子 (m - 1, n - 1) 的路径数目：每一步你可以向右或者向下走，也就是如果格子存在的话，可以从格子 (i, j) 走到格子 (i, j + 1) 或者格子 (i + 1, j) . 路径上经过的所有数字 XOR 异或值必须 等于 k . 请你返回满足上述条件的路径总数. 

5. 给你一个 n x n 的 方形 整数数组 matrix ，请你找出并返回通过 matrix 的下降路径 的 最小和 . 下降路径 可以从第一行中的任何元素开始，并从每一行中选择一个元素. 在下一行选择的元素和当前行所选元素最多相隔一列（即位于正下方或者沿对角线向左或者向右的第一个元素）. 具体来说，位置 (row, col) 的下一个元素应当是 (row + 1, col - 1)、(row + 1, col) 或者 (row + 1, col + 1) .

## 背包

### 01背包

> 在 0 - 1 背包问题中，有一个容量为 C 的背包和 n 个物品，每个物品有重量 w[i] 和价值 v[i]，目标是在不超过背包容量的前提下，选择一些物品使得总价值最大. 

- 状态定义
定义状态dp[i][j]表示前i个物品放入容量为j的背包中所能获得的最大价值. 
- 状态转移方程
当j < w[i]时，即背包容量不足以放入第i个物品，此时dp[i][j] = dp[i - 1][j]，即不放入第i个物品，价值与前i - 1个物品放入背包时相同. 
当j >= w[i]时，有两种选择：放入第i个物品或不放入. 放入时，价值为dp[i - 1][j - w[i]] + v[i]；不放入时，价值为dp[i - 1][j]. 取两者中的较大值，即dp[i][j] = max(dp[i - 1][j - w[i]] + v[i], dp[i - 1][j]). 
- 初始化
dp[0][j] = 0，表示没有物品放入背包时，价值为 0. 
dp[i][0] = 0，表示背包容量为 0 时，价值为 0. 
- 计算顺序
按照物品的数量i从 1 到n，背包容量j从 1 到C的顺序进行计算. 
- 最终答案
dp[n][C]即为将n个物品放入容量为C的背包中所能获得的最大价值.
