# 模型量化

## Reference

- https://medium.com/@florian_algo/model-quantization-1-basic-concepts-860547ec6aa9


以下是关于**模型量化（Model Quantization）**的总结，结合文档内容与核心要点：


### **一、定义与核心目标**
- **本质**：通过将神经网络中的**高精度浮点数参数/数据（如FP32）转换为低精度数值（如INT8、INT4）**，实现模型压缩与优化的技术。
- **核心目标**：  
  1. **减少内存占用**：降低模型存储体积，适配资源受限设备（如消费级GPU、边缘设备）。  
  2. **加速推理速度**：利用硬件对低精度计算的优化（如INT4矩阵乘法），减少数据传输与计算耗时。  
  3. **降低能耗**：减少内存访问次数，适合移动端或节能场景。


### **二、核心原理与关键概念**
#### **1. 量化的数学本质**
- **函数映射**：将连续的高精度数值映射到离散的低精度数值集合。  
  例：将FP32浮点数映射到INT4的16个离散值（0-15或-8-7）。  
- **关键公式**（线性量化）：  
  - 量化：`q = round((x / scale) + zero_point)`  
  - 反量化：`x_approx = (q - zero_point) * scale`  
  （`scale`为缩放因子，`zero_point`为零点偏移量，用于平衡精度与范围）。

#### **2. 定点数 vs. 浮点数**
| **特性**         | **定点数**                          | **浮点数**                          |
|------------------|-------------------------------------|-------------------------------------|
| **小数点位置**    | 固定（如前5位整数+后3位小数）       | 可变（通过指数位动态调整）          |
| **表示范围**      | 窄（受位数限制，如8位整数最大31）   | 宽（32位FP可表示±3.4e38）           |
| **精度**          | 低（小数位固定，精度受限）          | 高（尾数位数决定有效数字）          |
| **计算复杂度**    | 低（仅整数运算）                    | 高（需处理指数、尾数及归一化）      |
| **应用场景**      | 早期计算机、简单嵌入式系统          | 现代计算机、深度学习模型            |

#### **3. 量化类型**
- **按位数**：INT8（最常用）、INT4（更低内存，精度损失更高）、FP16/FP8（混合精度）。  
- **按阶段**：  
  - **训练后量化（PTQ）**：直接对训练好的模型量化，无需重新训练（快速但可能精度损失大）。  
  - **量化感知训练（QAT）**：训练过程中模拟低精度计算，优化模型适应量化（精度更高）。  
- **按粒度**：  
  - **逐层量化**：对每层单独量化（简单高效）。  
  - **逐通道量化**：对每层不同通道单独量化（精度更高，计算更复杂）。


### **三、量化对象**
1. **权重（Weights）**：  
   - 最常见量化对象，直接减少模型体积（如7B参数模型从FP32的28GB压缩至INT4的3.5GB）。  
2. **激活值（Activations）**：  
   - 占推理时内存消耗的主要部分，量化后可结合权重量化实现整数计算加速。  
3. **KV缓存（KV Cache）**：  
   - 对长序列生成（如文本续写）至关重要，量化可减少缓存占用，提升吞吐量。  
4. **梯度（Gradients）**：  
   - 主要用于训练阶段，减少分布式训练的通信开销（如FP16梯度替代FP32）。


### **四、优缺点与适用场景**
#### **优点**  
- **内存大幅压缩**：INT4/INT8量化可使模型内存占用降低至FP32的1/8~1/4。  
- **推理速度提升**：在支持低精度计算的硬件（如NVIDIA GPU的Tensor Cores）上，计算效率显著提高。  
- **部署成本降低**：允许在消费级设备（如RTX 3090）或边缘设备运行大型模型。  

#### **缺点**  
- **精度损失**：低位数量化可能导致模型性能下降（尤其复杂推理任务）。  
- **硬件依赖**：需硬件支持低精度计算（如非所有CPU/GPU均优化INT4）。  
- **兼容性问题**：部分模型架构（如自定义层）量化支持不完善。  

#### **适用场景**  
- **边缘计算**：手机、IoT设备（内存与功耗受限）。  
- **低成本云服务**：使用小规格GPU部署LLM推理服务。  
- **长序列生成**：量化KV缓存提升文本生成效率（如ChatGPT类应用）。  


### **五、典型应用与案例**
- **QLoRA**：通过4位量化+LoRA微调，将650亿参数模型的微调内存从780GB降至48GB，且精度接近FP16基线。  
- **Hugging Face Transformers**：支持BitsAndBytes库实现4/8位量化，兼容Llama、Qwen等模型。  
- **GPTQ/AWQ**：专用4位量化技术，通过量化感知训练或自适应权重优化，平衡精度与压缩率。  


### **六、发展趋势**
- **混合精度量化**：结合不同位数（如权重INT4+激活值FP16），兼顾精度与效率。  
- **动态量化**：推理时动态调整缩放因子，减少精度损失（如AWQ技术）。  
- **量化与架构优化结合**：如模块化模型设计（MoE）与量化协同，进一步降低推理成本。  


### **总结**  
模型量化是大语言模型落地的核心技术之一，通过牺牲部分精度换取内存、速度与成本的显著优化。随着硬件支持与算法改进（如QLoRA、GPTQ），量化正从“精度妥协”走向“高效协同”，成为边缘部署、低成本推理的关键解决方案。未来，混合精度、动态量化与模型架构创新的结合将推动量化技术更广泛应用。
