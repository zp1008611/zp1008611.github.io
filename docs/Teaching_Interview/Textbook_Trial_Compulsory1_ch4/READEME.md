# 指数函数与对数函数

## 4.1 指数

### 知识点总结

1. **n次方根**：如果$x^{n}=a$（$n\gt1$且$n\in N^{*}$），那么$x$叫做$a$的$n$次方根. 当$n$为奇数时，正数的$n$次方根是正数，负数的$n$次方根是负数，记为$\sqrt[n]{a}$；当$n$为偶数时，正数的$n$次方根有两个且互为相反数，记为$\pm\sqrt[n]{a}$（$a\gt0$），负数没有偶次方根，$0$的任何次方根都是$0$. 且$(\sqrt[n]{a})^{n}=a$ ，当$n$为奇数时，$\sqrt[n]{a^{n}} = a$；当$n$为偶数时，$\sqrt[n]{a^{n}} = |a|$. 
2. **分数指数幂**：正数的正分数指数幂$a^{\frac{m}{n}}=\sqrt[n]{a^{m}}$（$a\gt0$，$m,n\in N^{*}$，$n\gt1$）；正数的负分数指数幂$a^{-\frac{m}{n}}=\frac{1}{a^{\frac{m}{n}}}=\frac{1}{\sqrt[n]{a^{m}}}$（$a\gt0$ ，$m,n\in N^{*}$，$n\gt1$）；$0$的正分数指数幂为$0$，$0$的负分数指数幂无意义. 规定分数指数幂意义后，幂$a^{x}$中指数$x$取值范围拓展到有理数，且整数指数幂运算性质对有理数指数幂同样适用，即$a^{r}a^{s}=a^{r + s}$，$(a^{r})^{s}=a^{rs}$ ，$(ab)^{r}=a^{r}b^{r}$（$a\gt0$，$b\gt0$，$r,s\in Q$）. 
3. **无理数指数幂**：通过有理数指数幂逼近的方法定义无理数指数幂，无理数指数幂$a^{\alpha}$（$a\gt0$，$\alpha$为无理数）是一个确定的实数，指数幂$a^{x}$（$a\gt0$）中指数$x$取值范围拓展到实数，整数指数幂运算性质对实数指数幂也适用.  

### “指数”十分钟逐字讲稿
同学们好！在之前学习函数的时候，我们接触过像$y = x^{2}$、$y = x^{\frac{1}{2}}$这样的式子，这里的指数在我们后续深入研究函数的过程中非常重要. 为了更全面地探索函数的奥秘，今天我们要一起学习指数相关的知识，把指数的范围从我们熟悉的整数拓展到全体实数. （板书课题：4.1指数）

在初中，我们已经学过整数指数幂. 现在，我们先来回顾一下平方根和立方根的知识. 如果$x^{2}=a$，$x$就是$a$的平方根，比如$4$的平方根是$\pm2$；如果$x^{3}=a$ ，$x$就是$a$的立方根，像$8$的立方根是$2$. 那类似地，因为$(\pm2)^{4}=16$，所以$\pm2$就是$16$的$4$次方根；$2^{5}=32$，$2$就是$32$的$5$次方根. 

一般来说，如果$x^{n}=a$（$n\gt1$且$n\in N^{*}$），$x$就叫做$a$的$n$次方根. 这里要注意啦，当$n$是奇数的时候，正数的$n$次方根是一个正数，负数的$n$次方根是一个负数，我们用$\sqrt[n]{a}$来表示，比如$\sqrt[5]{32}=2$ ，$\sqrt[5]{-32}=-2$. 当$n$是偶数时，正数的$n$次方根有两个，它们互为相反数，正数$a$的正的$n$次方根用$\sqrt[n]{a}$表示，负的用$-\sqrt[n]{a}$表示，合起来就是$\pm\sqrt[n]{a}$（$a\gt0$ ），像$\sqrt[4]{16}=2$ ，$-\sqrt[4]{16}=-2$ ，$\pm\sqrt[4]{16}=\pm2$. 不过负数是没有偶次方根的，$0$的任何次方根都是$0$ ，写成$\sqrt[n]{0}=0$. 式子$\sqrt[n]{a}$叫做根式，$n$是根指数，$a$是被开方数. 

我们来思考一下，$\sqrt[n]{a^{n}}$一定等于$a$吗？其实不一定哦. 当$n$为奇数时，$\sqrt[n]{a^{n}} = a$；当$n$为偶数时，$\sqrt[n]{a^{n}} = |a|$ ，也就是$a\geq0$时，$\sqrt[n]{a^{n}} = a$ ，$a\lt0$时，$\sqrt[n]{a^{n}} = -a$. 比如说$\sqrt[3]{(-8)^{3}}=-8$ ，而$\sqrt{(-10)^{2}} = | - 10| = 10$. 

学习了$n$次方根后，我们再来看看分数指数幂. 当根式的被开方数的指数能被根指数整除时，根式可以写成幂的形式，像$\sqrt[5]{a^{10}}=\sqrt[5]{(a^{2})^{5}} = a^{2}=a^{\frac{10}{5}}$（$a\gt0$ ）. 那当指数不能被整除时呢？其实也可以写成幂的形式. 我们规定，正数的正分数指数幂$a^{\frac{m}{n}}=\sqrt[n]{a^{m}}$（$a\gt0$，$m,n\in N^{*}$，$n\gt1$） ，正数的负分数指数幂$a^{-\frac{m}{n}}=\frac{1}{a^{\frac{m}{n}}}=\frac{1}{\sqrt[n]{a^{m}}}$（$a\gt0$ ，$m,n\in N^{*}$，$n\gt1$） . $0$的正分数指数幂等于$0$ ，$0$的负分数指数幂没有意义. 这样，指数$x$的取值范围就从整数拓展到了有理数，而且整数指数幂的运算性质对有理数指数幂也同样适用. 

例如计算$8^{\frac{2}{3}}$ ，我们可以把$8$写成$2^{3}$，那么$8^{\frac{2}{3}}=(2^{3})^{\frac{2}{3}} = 2^{3\times\frac{2}{3}} = 2^{2}=4$ ；再比如计算$(\frac{16}{81})^{-\frac{3}{4}}$ ，先把它变成$(\frac{81}{16})^{\frac{3}{4}}$ ，再进一步计算$(\frac{3^{4}}{2^{4}})^{\frac{3}{4}} = (\frac{3}{2})^{4\times\frac{3}{4}} = (\frac{3}{2})^{3}=\frac{27}{8}$. 

接下来，我们把指数的范围再拓展一下，看看无理数指数幂. 以$5^{\sqrt{2}}$为例，我们通过$\sqrt{2}$的不足近似值$x$和过剩近似值$y$，计算相应的$5^{x}$和$5^{y}$的近似值. 可以发现，当$x$和$y$逐渐逼近$\sqrt{2}$时，$5^{x}$和$5^{y}$都趋向于同一个数，这个数就是$5^{\sqrt{2}}$，这说明无理数指数幂$a^{\alpha}$（$a\gt0$，$\alpha$为无理数）是一个确定的实数. 至此，指数幂$a^{x}$（$a\gt0$）中指数$x$的取值范围就拓展到了实数，整数指数幂的运算性质对实数指数幂同样适用. 

下面我们通过例题来巩固一下这些知识. 例1：计算$a^{2}\cdot\sqrt[3]{a^{2}}$ （$a\gt0$） ，根据分数指数幂的定义，$\sqrt[3]{a^{2}} = a^{\frac{2}{3}}$ ，所以$a^{2}\cdot\sqrt[3]{a^{2}} = a^{2}a^{\frac{2}{3}} = a^{2 + \frac{2}{3}} = a^{\frac{8}{3}}$ . 

例2：计算$(2a^{\frac{2}{3}}b^{\frac{1}{2}})( - 6a^{\frac{1}{2}}b^{\frac{1}{3}})\div( - 3a^{\frac{1}{6}}b^{\frac{5}{6}})$ （$a\gt0$，$b\gt0$） ，我们根据指数幂的运算性质，系数相乘除，同底数幂相乘除，得到$[2\times( - 6)\div( - 3)]a^{\frac{2}{3}+\frac{1}{2}-\frac{1}{6}}b^{\frac{1}{2}+\frac{1}{3}-\frac{5}{6}} = 4a$ . 

现在，请大家做几道练习题. 练习1：用根式的形式表示$a^{\frac{1}{2}}$（$a\gt0$） ；练习2：用分数指数幂的形式表示并计算$\sqrt[3]{x^{2}}$（$x\gt0$） ；练习3：计算$(\frac{36}{49})^{\frac{3}{2}}$. 

通过今天的学习，我们从$n$次方根开始，一步步将指数的范围从整数拓展到了有理数，再到实数. 学习了分数指数幂和无理数指数幂的定义，以及指数幂的运算性质. 这些知识是我们后续学习指数函数的重要基础，大家课后要多做练习，加深理解. 下节课我们将基于今天所学，进一步探索指数函数的奥秘. 今天的课就到这里，下课！ 

## 4.2 指数函数

### 知识点总结
1. **指数函数的定义**：一般地，函数$y = a^{x}$（$a > 0$，且$a\neq1$）叫做指数函数，其中指数$x$是自变量，定义域是$R$. 指数函数常用来刻画指数增长（$a>1$）或指数衰减（$0 < a < 1$）的变化规律，如景区游客人次增长、生物体内碳14衰减等问题. 
2. **指数函数的图象与性质**：通过绘制$y = 2^{x}$、$y = (\frac{1}{2})^{x}$等具体指数函数图象并观察发现，指数函数图象按底数$a$的取值分为$0 < a < 1$和$a > 1$两种类型. 其性质包括：定义域为$R$，值域为$(0, +\infty)$；都过定点$(0, 1)$，即$x = 0$时，$y = 1$；当$0 < a < 1$时，函数为减函数，当$a > 1$时，函数为增函数 . 
3. **指数函数的应用**：利用指数函数的单调性比较两个指数式的大小，如比较$1.7^{2.5}$与$1.7^{3}$，因为$y = 1.7^{x}$是增函数且$2.5 < 3$，所以$1.7^{2.5} < 1.7^{3}$. 还可应用于解决实际问题，如计算人口增长、放射性物质衰减、储蓄本利和等问题. 

### “指数函数”十分钟逐字讲稿
同学们好！之前我们学习了指数的相关知识，把指数的范围拓展到了实数. 现在，我们要基于这些知识，认识一种新的函数——指数函数. 它在生活中的应用非常广泛，比如经济增长、人口变化、放射性物质衰减等问题都能用它来描述. 让我们一起走进指数函数的世界，探索其中的奥秘吧！（板书课题：4.2指数函数）

先来看两个实际问题. 问题一，随着生活水平提高，旅游越来越热门. A、B两地景区从2001年起采取不同措施，A地提高门票价格，B地取消门票. 观察两地景区2001 - 2015年游客人次的数据表和图象（展示数据表和图象），A地景区游客人次近似直线上升，年增加量大致相等；而B地景区游客人次是非线性增长，年增加量越来越大. 进一步探究发现，从2002年起，B地景区每年游客人次除以上一年的游客人次，结果都约为1.11，这意味着B地景区游客人次的年增长率约为0.11，是一个常数，这种增长方式就是指数增长. 如果设经过$x$年后游客人次是2001年的$y$倍，就可以得到函数$y = 1.11^{x}$（$x \in [0, +\infty)$） . 

再看问题二，生物死亡后，体内碳14会按一定比率衰减，大约每5730年衰减为原来的一半. 设死亡生物体内碳14含量的年衰减率为$p$ ，经过推导可得$p = 1 - (\frac{1}{2})^{\frac{1}{5730}}$ . 设生物死亡年数为$x$，死亡生物体内碳14含量为$y$ ，则$y = (\frac{1}{2})^{\frac{x}{5730}}$ （$x \in [0, +\infty)$） ，这就是指数衰减的例子. 

像$y = 1.11^{x}$和$y = (\frac{1}{2})^{\frac{x}{5730}}$这样的函数，都可以写成$y = a^{x}$（$a > 0$，且$a\neq1$）的形式，这就是指数函数的定义. 其中指数$x$是自变量，定义域是$R$ . 

下面我们来研究指数函数的图象和性质. 先以$y = 2^{x}$为例，大家填写这个表格（展示表格），然后用描点法画出它的图象. （稍作停顿，给学生时间思考和画图）画好后，我们再来探究$y = (\frac{1}{2})^{x}$的图象. 因为$y = (\frac{1}{2})^{x} = 2^{-x}$ ，点$(x, y)$与点$(-x, y)$关于$y$轴对称，所以$y = 2^{x}$与$y = (\frac{1}{2})^{x}$的图象关于$y$轴对称，我们可以利用这个性质画出$y = (\frac{1}{2})^{x}$的图象（在黑板上或借助多媒体展示画图过程） . 

接着，我们选取不同的底数$a$（$a > 0$，且$a\neq1$），在同一直角坐标系内画出相应指数函数的图象（展示多个指数函数图象）. 通过观察这些图象，我们发现指数函数的图象和性质可以分为$0 < a < 1$和$a > 1$两种情况. 它们的定义域都是$R$，值域都是$(0, +\infty)$，都过定点$(0, 1)$ . 当$0 < a < 1$时，函数是减函数；当$a > 1$时，函数是增函数. 

掌握了指数函数的性质，我们就可以用它来解决一些问题. 比如比较两个指数式的大小，看这道例题：比较$1.7^{2.5}$和$1.7^{3}$的大小. 因为$y = 1.7^{x}$中底数$1.7 > 1$，函数是增函数，又因为$2.5 < 3$ ，所以$1.7^{2.5} < 1.7^{3}$ .

## 4.3 对数

### 知识点总结
1. **对数的定义**：如果$a^{x}=N$（$a>0$，且$a≠1$），那么数$x$叫做以$a$为底$N$的对数，记作$x=\log_{a}N$ ，其中$a$是底数，$N$是真数。以10为底的对数叫常用对数，记为$\lg N$；以无理数$e=2.71828\cdots$为底的对数叫自然对数，记为$\ln N$ 。对数与指数的关系为$a^{x}=N\Leftrightarrow x=\log_{a}N$（$a>0$，$a≠1$），由此可得负数和0没有对数，$\log_{a}1 = 0$ ，$\log_{a}a = 1$。
2. **对数的运算性质**：若$a>0$，且$a≠1$ ，$M>0$ ，$N>0$，则有$\log_{a}(MN)=\log_{a}M+\log_{a}N$；$\log_{a}\frac{M}{N}=\log_{a}M - \log_{a}N$；$\log_{a}M^{n}=n\log_{a}M$（$n\in R$）。
3. **对数换底公式**：$\log_{a}b=\frac{\log_{c}b}{\log_{c}a}$（$a>0$，且$a≠1$；$b>0$；$c>0$ ，且$c≠1$）。利用换底公式可将不同底数的对数转化为常用对数或自然对数进行计算。

### “对数”十分钟逐字讲稿
同学们好！上节课我们学习了指数函数，知道可以通过指数运算解决很多增长或衰减的问题。比如在研究景区游客人次增长模型$y = 1.11^{x}$时，能轻松算出经过$x$年后游客人次是2001年的多少倍。那现在反过来，如果想知道游客人次是2001年的2倍、3倍、4倍……时，需要经过多少年，该怎么解决呢？这就是今天我们要学习的对数的知识（板书课题：4.3对数）。

我们来看，像从$2 = 1.11^{x}$ ，$3 = 1.11^{x}$ ，$4 = 1.11^{x}$这些式子中求$x$，其实就是已知底数和幂的值，求指数，这时候就引出了对数的概念。一般地，如果$a^{x}=N$（$a>0$ ，且$a≠1$），那么数$x$就叫做以$a$为底$N$的对数，记作$x=\log_{a}N$ 。这里$a$是对数的底数，$N$是真数。比如说，因为$4^{2}=16$，所以以4为底16的对数就是2，写成$\log_{4}16 = 2$ 。在数学里，我们把以10为底的对数叫做常用对数，把$\log_{10}N$简记为$\lg N$；还有以无理数$e$为底的对数，叫做自然对数，把$\log_{e}N$记为$\ln N$ 。

对数和指数有着紧密的联系，当$a>0$ ，$a≠1$时，$a^{x}=N$和$x=\log_{a}N$是等价的，这就是对数与指数间的关系。从这个关系出发，我们能得到一些结论，比如负数和0没有对数，因为任何正数的任何次幂都是正数，不可能等于负数或0 ；还有$\log_{a}1 = 0$ ，因为$a^{0}=1$ ；$\log_{a}a = 1$ ，因为$a^{1}=a$ 。

下面我们通过例题来熟悉一下对数和指数的相互转化。例1，把$5^{4}=625$化为对数式，根据定义就是$\log_{5}625 = 4$ ；把$\log_{\frac{1}{2}}16 = - 4$化为指数式，就是$(\frac{1}{2})^{-4}=16$ 。

学习了对数的定义，我们再来探究对数的运算性质。我们知道指数幂有运算性质，那对数有没有类似的性质呢？设$M = a^{m}$ ，$N = a^{n}$ ，因为$a^{m}a^{n}=a^{m + n}$ ，所以$MN = a^{m + n}$ ，根据对数与指数的关系，就有$\log_{a}M = m$ ，$\log_{a}N = n$ ，$\log_{a}(MN)=m + n$ ，这样就得到了对数的一个运算性质：$\log_{a}(MN)=\log_{a}M+\log_{a}N$ 。同理，由$a^{m}÷a^{n}=a^{m - n}$和$(a^{m})^{n}=a^{mn}$ ，可以推出$\log_{a}\frac{M}{N}=\log_{a}M - \log_{a}N$ ，$\log_{a}M^{n}=n\log_{a}M$（$n\in R$）。

比如计算$\lg\sqrt[5]{100}$ ，我们可以先把它变形为$\lg100^{\frac{1}{5}}$ ，根据对数运算性质，就是$\frac{1}{5}\lg100$ ，而$\lg100 = 2$ ，所以结果就是$\frac{2}{5}$ 。

在实际计算中，有时候我们需要把不同底数的对数转化为常用对数或自然对数来计算，这就用到对数换底公式。设$\log_{a}b = x$ ，则$a^{x}=b$ ，两边同时取以$c$为底的对数，得到$\log_{c}a^{x}=\log_{c}b$ ，再根据对数运算性质，$x\log_{c}a=\log_{c}b$ ，所以$\log_{a}b=\frac{\log_{c}b}{\log_{c}a}$（$a>0$ ，且$a≠1$；$b>0$；$c>0$ ，且$c≠1$）。

例如在之前景区游客人次的问题里，求经过多少年游客人次是2001年的2倍，就是计算$x=\log_{1.11}2$ ，利用换底公式可得$x=\frac{\lg2}{\lg1.11}$ ，用计算工具算出大约是7年。

下面请大家做几道练习题巩固一下。练习1：把$2^{3}=8$写成对数式，把$\log_{3}9 = 2$写成指数式。练习2：计算$\log_{3}(27×9^{2})$的值。

通过今天的学习，我们知道了对数是怎么定义的，它和指数有什么关系，还学习了对数的运算性质和换底公式。对数在很多领域都有重要应用，希望大家课后多做练习，加深对这些知识的理解。下节课我们会继续学习与对数相关的更深入的内容。今天的课就到这里，下课！ 

## 4.4 对数函数

### 知识点总结
1. **对数函数的概念**：一般地，函数$y=\log_{a}x$（$a>0$，且$a≠1$）叫做对数函数，$x$是自变量，定义域是$(0, +\infty)$。由指数函数$y = a^{x}$（$a>0$，且$a≠1$）通过指数与对数的关系可得对数函数，二者定义域与值域互换。例如，从$y = (\frac{1}{2})^{x}$可得$x=\log_{\frac{1}{2}}y$，变形后为对数函数$y=\log_{\frac{1}{2}}x$ 。
2. **对数函数的图象与性质**：对数函数$y=\log_{a}x$（$a>0$，且$a≠1$）的图象按底数$a$的取值分为$0 < a < 1$和$a > 1$两种类型。它们都过定点$(1,0)$ ，定义域为$(0, +\infty)$，值域为$R$。当$0 < a < 1$时，函数为减函数；当$a > 1$时，函数为增函数。底数互为倒数的两个对数函数图象关于$x$轴对称 。
3. **对数函数的应用**：利用对数函数的单调性比较对数的大小。如比较$\log_{2}3.4$与$\log_{2}8.5$ ，因为$y=\log_{2}x$是增函数且$3.4<8.5$ ，所以$\log_{2}3.4<\log_{2}8.5$ 。
4. **反函数的概念**：指数函数$y = a^{x}$（$a>0$，且$a≠1$）与对数函数$y=\log_{a}x$（$a>0$，且$a≠1$）互为反函数，它们的定义域与值域正好互换，图象关于直线$y = x$对称。
5. **不同函数增长方式的差异**：指数函数$y = a^{x}$（$a>1$）增长速度越来越快，呈“指数爆炸”式增长；一次函数$y = kx$（$k>0$）增长速度保持不变；对数函数$y=\log_{a}x$（$a>1$）增长速度越来越慢。随着$x$增大，指数函数增长速度最终会远超一次函数，对数函数增长速度则远慢于一次函数。 

### “对数函数”十分钟逐字讲稿
同学们好！之前我们学习了指数函数，知道它能很好地描述增长或衰减的现象。比如在研究死亡生物体内碳14含量变化时，我们用指数函数$y = (\frac{1}{2})^{x}$表示碳14含量$y$随死亡时间$x$的衰减规律。那现在反过来想，如果我们知道了碳14的含量，想知道生物死亡了多长时间，该怎么办呢？这就引出了我们今天要学习的对数函数（板书课题：4.4对数函数）。

我们来看，根据指数与对数的关系，由$y = (\frac{1}{2})^{x}$（$x≥0$）可以得到$x=\log_{\frac{1}{2}}y$（$0<y≤1$）。对于任意一个$y$在$(0,1]$这个范围内，通过这个对应关系，在$[0, +\infty)$上都有唯一确定的$x$和它对应，所以$x$也是$y$的函数。通常我们习惯用$x$表示自变量，$y$表示函数，就把它写成$y=\log_{\frac{1}{2}}x$（$x\in(0,1]$） 。一般地，函数$y=\log_{a}x$（$a>0$，且$a≠1$）就是对数函数，它的定义域是$(0, +\infty)$。

我们来看几个例子，求函数$y=\log_{3}x^{2}$的定义域，因为对数中的真数要大于0，也就是$x^{2}>0$ ，解得$x≠0$，所以定义域是$\{x|x≠0\}$；再看$y=\log_{a}(4 - x)$（$a>0$，且$a≠1$） ，$4 - x>0$，解得$x<4$ ，定义域就是$\{x|x<4\}$ 。

接下来我们研究对数函数的图象和性质。先画函数$y=\log_{2}x$的图象，大家填写这个表格（展示表格），然后用描点法把它画出来。（稍作停顿，给学生时间思考和画图）画好后，我们来探究一下，像$y=\log_{2}x$和$y=\log_{\frac{1}{2}}x$这样底数互为倒数的对数函数，它们的图象有什么关系呢？利用换底公式可以得到$y=\log_{\frac{1}{2}}x = -\log_{2}x$ ，因为点$(x,y)$和点$(x, - y)$关于$x$轴对称，所以这两个函数的图象关于$x$轴对称，我们可以利用$y=\log_{2}x$的图象画出$y=\log_{\frac{1}{2}}x$的图象（在黑板上或借助多媒体展示画图过程） 。

我们再选取不同的底数$a$（$a>0$，且$a≠1$），在同一直角坐标系内画出相应对数函数的图象（展示多个对数函数图象）。通过观察这些图象，我们发现对数函数的图象和性质也可以分为$0 < a < 1$和$a > 1$两种情况。它们都过定点$(1,0)$ ，定义域是$(0, +\infty)$，值域是$R$ 。当$0 < a < 1$时，函数是减函数；当$a > 1$时，函数是增函数。

掌握了对数函数的性质，我们就可以用它来比较对数的大小。比如比较$\log_{2}3.4$和$\log_{2}8.5$ ，因为$y=\log_{2}x$的底数$2>1$，是增函数，又因为$3.4<8.5$ ，所以$\log_{2}3.4<\log_{2}8.5$ 。

在实际生活中，对数函数也有很多应用。比如在测量溶液酸碱度时，$pH = -\lg[H^{+}]$，根据对数函数的性质，我们可以知道溶液中氢离子浓度越大，$pH$越小，溶液酸性越强。

这里还有一个重要的概念，指数函数$y = a^{x}$（$a>0$，且$a≠1$）和对数函数$y=\log_{a}x$（$a>0$，且$a≠1$）互为反函数，它们的定义域和值域正好互换，图象关于直线$y = x$对称。

最后，我们来比较一下一次函数、指数函数和对数函数的增长方式。以$y = 2^{x}$和$y = 2x$为例，通过列表和画图可以发现，虽然它们都单调递增，但$y = 2^{x}$的增长速度越来越快，而$y = 2x$增长速度保持不变，随着$x$增大，$y = 2^{x}$的增长会远超$y = 2x$ 。对数函数$y=\lg x$和一次函数$y=\frac{1}{10}x$相比，$y=\lg x$的增长速度越来越慢 。
