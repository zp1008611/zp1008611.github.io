# 三角函数

## 5.1 任意角和弧度制

### 知识点总结
1. **任意角的概念**：角的概念从初中的基础上进行了推广，包括正角（射线按逆时针方向旋转形成）、负角（按顺时针方向旋转形成）和零角（射线未旋转）。在直角坐标系中讨论角，使角的顶点与原点重合，始边与x轴非负半轴重合，根据终边所在象限确定角是第几象限角，终边在坐标轴上的角不属于任何象限。与角$\alpha$终边相同的角的集合为$S = \{\beta|\beta = \alpha + k\cdot360^{\circ}, k\in Z\}$。
2. **弧度制的定义**：长度等于半径长的圆弧所对的圆心角叫做1弧度的角，用符号rad表示。在半径为$r$的圆中，弧长为$l$的弧所对圆心角为$\alpha rad$，则$|\alpha| = \frac{l}{r}$ ，角的正负由旋转方向决定。弧度制与角度制的换算关系为：$360^{\circ}=2\pi rad$，$180^{\circ}=\pi rad$，$1^{\circ}=\frac{\pi}{180}rad\approx0.01745rad$，$1rad = (\frac{180}{\pi})^{\circ}\approx57.30^{\circ}=57^{\circ}18'$。角的集合与实数集$R$在弧度制下建立起一一对应关系。
3. **扇形公式（弧度制）**：设扇形半径为$R$，圆心角为$\alpha(0\lt\alpha\lt2\pi)$ ，弧长为$l$，面积为$S$，则有$l=\alpha R$，$S=\frac{1}{2}\alpha R^{2}$，$S=\frac{1}{2}lR$。

### “任意角和弧度制”十分钟逐字讲稿
同学们好！在生活中，我们经常能看到像钟表指针转动、摩天轮旋转这样的圆周运动。比如在体操运动里，运动员会做出“前空翻转体540度”“后空翻转体720度”这些动作，这里涉及到的角度都超出了我们初中所学的0° - 360°的范围，而且旋转方向也不同。那怎么准确地描述这些角呢？这就是我们今天要学习的“任意角和弧度制”的内容（板书课题：5.1任意角和弧度制）。

首先，我们来学习任意角的概念。在初中，我们知道角可以看成是一条射线绕着它的端点旋转所成的图形。现在，我们规定射线绕端点按逆时针方向旋转形成的角是正角，按顺时针方向旋转形成的角是负角，如果射线没有旋转，那就是零角。比如说，正常情况下钟表的时针或分针旋转形成的角就是负角。这样，角的概念就被推广到了任意角，包含正角、负角和零角。

为了方便研究，我们通常在直角坐标系里讨论角。把角的顶点和原点重合，始边和x轴的非负半轴重合。角的终边在第几象限，这个角就是第几象限角；要是终边在坐标轴上，就认为这个角不属于任何象限。那对于给定的一条射线，以它为终边的角唯一吗？其实不唯一。像 - 32°角的终边是$OB$ ，328° 、 - 392°等角的终边也都是$OB$。所有和 - 32°角终边相同的角，都可以表示成 - 32°加上整数个周角，也就是集合$S = \{\beta|\beta = - 32^{\circ}+k\cdot360^{\circ}, k\in Z\}$ 里的元素。一般来说，与角$\alpha$终边相同的角都能写成$\alpha + k\cdot360^{\circ}$（$k\in Z$）这样的形式。

下面我们来看个例子，在0° - 360°范围内，找出与 - 950°12′角终边相同的角。我们可以把 - 950°12′写成$129^{\circ}48' - 3\times360^{\circ}$，所以在这个范围内，和它终边相同的角就是$129^{\circ}48'$ ，它是第二象限角。

学习了任意角之后，我们来了解角的另一种度量单位制——弧度制。我们平常度量角用的是角度制，1度的角是周角的$\frac{1}{360}$。那弧度制是怎么定义的呢？长度等于半径长的圆弧所对的圆心角就是1弧度的角，用rad表示。在半径为$r$的圆里，弧长为$l$的弧所对圆心角为$\alpha rad$ ，它们的关系是$|\alpha| = \frac{l}{r}$ ，这里$\alpha$的正负由角的旋转方向决定。

弧度制和角度制之间是可以换算的。因为周角在角度制下是360°，在弧度制下是$2\pi rad$，所以$360^{\circ}=2\pi rad$ ，$180^{\circ}=\pi rad$ ，由此可以推出$1^{\circ}=\frac{\pi}{180}rad\approx0.01745rad$ ，$1rad = (\frac{180}{\pi})^{\circ}\approx57.30^{\circ}=57^{\circ}18'$ 。比如把67°30′化成弧度，先把它变成$(\frac{135}{2})^{\circ}$ ，再乘以$\frac{\pi}{180}$ ，得到$\frac{3}{8}\pi rad$ ，近似值约为1.178rad。

在弧度制下，角的集合和实数集$R$是一一对应的，每一个角都有唯一的实数（也就是它的弧度数）与之对应，反过来也一样。而且，弧度制下的扇形公式也很简洁。设扇形半径是$R$ ，圆心角是$\alpha(0\lt\alpha\lt2\pi)$ ，弧长是$l$ ，面积是$S$ ，就有$l=\alpha R$ ，$S=\frac{1}{2}\alpha R^{2}$ ，$S=\frac{1}{2}lR$。

接下来，我们做几道练习题巩固一下。练习1：把22°30′化成弧度；练习2：写出终边在x轴上的角的集合（用弧度表示）。

通过今天的学习，我们知道了角的概念被推广到了任意角，还学习了弧度制以及它和角度制的换算，还有弧度制下的扇形公式。这些知识是我们后续学习三角函数的重要基础，大家课后要认真复习，多做练习题。下节课我们会继续深入学习三角函数的相关内容。今天的课就到这里，下课！ 

## 5.2 三角函数的概念

### 知识点总结
1. **三角函数的概念**：在单位圆中，以圆心$O$为原点，射线$OA$为$x$轴非负半轴建立直角坐标系。对于任意角$\alpha$，其终边$OP$与单位圆交点$P(x,y)$，定义$y = \sin\alpha$（正弦函数），$x = \cos\alpha$（余弦函数），当$x\neq0$时，$\frac{y}{x}=\tan\alpha$（正切函数） 。三角函数的定义域分别为：$y = \sin x$，$x\in R$；$y = \cos x$，$x\in R$；$y = \tan x$，$x\in\{x|x\neq\frac{\pi}{2}+k\pi,k\in Z\}$。终边相同的角的同一三角函数值相等，即$\sin(\alpha + k\cdot2\pi)=\sin\alpha$，$\cos(\alpha + k\cdot2\pi)=\cos\alpha$，$\tan(\alpha + k\cdot2\pi)=\tan\alpha$（$k\in Z$）。
2. **三角函数值的求解与符号判断**：根据三角函数定义，已知角终边上一点坐标可求三角函数值；根据角所在象限可判断三角函数值的符号，如第一象限角的正弦、余弦、正切值均为正，第二象限角正弦值为正，余弦、正切值为负等。利用公式一可将求任意角的三角函数值转化为求$0\sim2\pi$（或$0^{\circ}\sim360^{\circ}$）角的三角函数值。
3. **同角三角函数的基本关系**：同一个角$\alpha$的正弦、余弦的平方和等于1，即$\sin^{2}\alpha + \cos^{2}\alpha = 1$；当$\alpha\neq k\pi+\frac{\pi}{2}(k\in Z)$时，正弦与余弦的商等于角$\alpha$的正切，即$\frac{\sin\alpha}{\cos\alpha}=\tan\alpha$。利用这些关系，已知一个三角函数值可求其他三角函数值，还可进行三角恒等式的证明和化简。 

### “三角函数的概念”十分钟逐字讲稿
同学们好！上节课我们学习了任意角和弧度制，知道角的范围已经扩展到了全体实数。今天我们就借助这些知识，来研究单位圆上点的运动，建立一个数学模型，看看如何刻画点的位置变化，这就是我们今天要学习的三角函数（板书课题：5.2三角函数的概念）。

我们先来看三角函数的定义。在单位圆中，以圆心$O$为原点，以射线$OA$为$x$轴的非负半轴建立直角坐标系，点$A$坐标是$(1,0)$。当射线$OA$绕点$O$按逆时针方向旋转角$\alpha$，终止位置为$OP$，点$P$坐标为$(x,y)$。大家想想，当$\alpha=\frac{\pi}{6}$时，点$P$的坐标是什么呢？对，是$(\frac{\sqrt{3}}{2},\frac{1}{2})$；当$\alpha=\frac{\pi}{2}$时，点$P$坐标是$(0,1)$；当$\alpha=\frac{2\pi}{3}$时，点$P$坐标是$(-\frac{1}{2},\frac{\sqrt{3}}{2})$ 。可以发现，对于任意给定的一个角$\alpha\in R$，它的终边$OP$与单位圆交点$P$的坐标，无论是横坐标$x$还是纵坐标$y$，都是唯一确定的。

基于此，我们给出三角函数的定义：点$P$的纵坐标$y$叫做$\alpha$的正弦函数，记作$y = \sin\alpha$；点$P$的横坐标$x$叫做$\alpha$的余弦函数，记作$x = \cos\alpha$；当$x\neq0$时，点$P$的纵坐标与横坐标的比值$\frac{y}{x}$叫做$\alpha$的正切，记作$\tan\alpha$。这里要注意，当$\alpha=\frac{\pi}{2}+k\pi(k\in Z)$时，$\tan\alpha$无意义哦。我们把正弦函数、余弦函数和正切函数统称为三角函数。

我们来做个例题巩固一下，求$\frac{5\pi}{3}$的正弦、余弦和正切值。在直角坐标系中作出$\angle AOB=\frac{5\pi}{3}$，可以知道它的终边与单位圆交点坐标为$(\frac{1}{2},-\frac{\sqrt{3}}{2})$，所以$\sin\frac{5\pi}{3}=-\frac{\sqrt{3}}{2}$，$\cos\frac{5\pi}{3}=\frac{1}{2}$ ，$\tan\frac{5\pi}{3}=-\sqrt{3}$。

学习了定义，我们再来研究三角函数的一些性质。先看定义域，正弦函数和余弦函数的定义域都是$R$，正切函数的定义域是$x\in\{x|x\neq\frac{\pi}{2}+k\pi,k\in Z\}$ 。那三角函数值在各象限的符号是怎样的呢？第一象限角的正弦、余弦、正切值都为正；第二象限角正弦值为正，余弦、正切值为负；第三象限角正切值为正，正弦、余弦值为负；第四象限角余弦值为正，正弦、正切值为负。比如$250^{\circ}$是第三象限角，所以$\cos250^{\circ}<0$ 。而且终边相同的角的同一三角函数值相等，这就是公式一：$\sin(\alpha + k\cdot2\pi)=\sin\alpha$，$\cos(\alpha + k\cdot2\pi)=\cos\alpha$ ，$\tan(\alpha + k\cdot2\pi)=\tan\alpha$（$k\in Z$），利用这个公式可以把求任意角的三角函数值转化为求$0\sim2\pi$角的三角函数值。

接下来我们学习同角三角函数的基本关系。大家看，在单位圆中，设点$P(x,y)$是角$\alpha$的终边与单位圆的交点，由勾股定理可得$x^{2}+y^{2}=1$，也就是$\sin^{2}\alpha + \cos^{2}\alpha = 1$ ，这个公式在$\alpha$的终边与坐标轴重合时也成立。当$\alpha\neq k\pi+\frac{\pi}{2}(k\in Z)$时，还有$\frac{\sin\alpha}{\cos\alpha}=\tan\alpha$。比如说，已知$\sin\alpha=-\frac{3}{5}$，由$\sin^{2}\alpha + \cos^{2}\alpha = 1$可以求出$\cos^{2}\alpha = 1 - (-\frac{3}{5})^{2}=\frac{16}{25}$ ，因为$\sin\alpha<0$且$\sin\alpha\neq - 1$，所以$\alpha$是第三或第四象限角。如果是第三象限角，$\cos\alpha=-\frac{4}{5}$，$\tan\alpha=\frac{3}{4}$；如果是第四象限角，$\cos\alpha=\frac{4}{5}$ ，$\tan\alpha=-\frac{3}{4}$。

下面请大家做几道练习题。练习1：求$0$，$\frac{\pi}{2}$ ，$\pi$ ，$\frac{3\pi}{2}$的三个三角函数值。练习2：已知$\cos\alpha=-\frac{4}{5}$，且$\alpha$为第三象限角，求$\sin\alpha$，$\tan\alpha$的值。
