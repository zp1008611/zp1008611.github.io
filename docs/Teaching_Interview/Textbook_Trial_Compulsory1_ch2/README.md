## 2.1 等式性质与不等式性质



### 知识点总结  
1. **不等关系的实际应用**  
   - 现实中存在大量不等关系（如限速、质量检测、几何性质等），可用不等式或不等式组表示。  
   - 例：限速40km/h表示为 $0 < v \leq 40$，酸奶成分要求表示为 $\begin{cases} f \geq 2.5\% \\ p \geq 2.3\% \end{cases}$。  

2. **实数大小比较的基本事实**  
   - 对于任意实数 $a, b$：  
     \[
     a > b \Leftrightarrow a - b > 0, \quad a = b \Leftrightarrow a - b = 0, \quad a < b \Leftrightarrow a - b < 0.
     \]  
   - 比较两数大小可转化为判断它们的差与0的关系（作差法）。  

3. **重要不等式：$a^2 + b^2 \geq 2ab$**  
   - 推导：由完全平方公式 $(a - b)^2 \geq 0$，得 $a^2 + b^2 - 2ab \geq 0$，即 $a^2 + b^2 \geq 2ab$。  
   - 等号成立条件：当且仅当 $a = b$ 时取等号。  

4. **不等式的基本性质**  
   - **对称性**：$a > b \Leftrightarrow b < a$。  
   - **传递性**：$a > b, b > c \Rightarrow a > c$。  
   - **可加性**：$a > b \Rightarrow a + c > b + c$（不等式两边加同一实数，方向不变）。  
   - **可乘性**：若 $a > b, c > 0$，则 $ac > bc$；若 $a > b, c < 0$，则 $ac < bc$（乘正数方向不变，乘负数方向改变）。  
   - **同向可加性**：$a > b, c > d \Rightarrow a + c > b + d$。  
   - **正数同向可乘性**：$a > b > 0, c > d > 0 \Rightarrow ac > bd$。  


### “等式性质与不等式性质”十分钟逐字讲稿  

#### 引入（1分钟）  
同学们好！上节课我们在集合的世界里探索了元素与集合的关系、集合间的运算。今天咱们回到现实生活——大家有没有注意到，马路上的限速标志、食品包装上的成分表，甚至连三角形的边长关系，都藏着数学的秘密？这些“多与少”“大与小”的关系，就是我们今天要研究的 **不等式**。让我们从如何用不等式表示这些关系开始吧！（板书课题：2.1 等式性质与不等式性质）  


#### 知识点讲解（5分钟）  
### 一、不等关系：从生活到数学  
先看几个例子：  
1. 某路段限速40km/h，汽车速度 $v$ 必须满足 $0 < v \leq 40$，这里“不超过”就是“≤”的意思。  
2. 酸奶中脂肪含量 $f$ 不少于2.5%，蛋白质含量 $p$ 不少于2.3%，写成不等式组就是 $\begin{cases} f \geq 2.5\% \\ p \geq 2.3\% \end{cases}$。  
这些例子说明，不等关系能精准描述现实中的数量限制。  

### 二、实数比较：作差法的魔法  
怎么比较两个实数的大小呢？比如 $a$ 和 $b$，如果 $a - b$ 是正数，说明 $a > b$；如果差是0，就是 $a = b$；差是负数，就是 $a < b$。这就是 **作差法** 的原理。比如比较 $(x+2)(x+3)$ 和 $(x+1)(x+4)$，我们只需要算它们的差：  
\[
(x+2)(x+3) - (x+1)(x+4) = (x²+5x+6) - (x²+5x+4) = 2 > 0，
\]  
所以前者更大。作差法是解决不等式问题的“金钥匙”哦！  

### 三、重要不等式：从风车会标说起  
还记得北京国际数学家大会的会标吗？它由4个直角三角形组成正方形（画图示意）。设直角边为 $a, b$，正方形面积是 $a² + b²$，4个三角形面积和是 $2ab$。因为正方形面积不小于三角形面积和，所以 $a² + b² \geq 2ab$，当且仅当 $a = b$ 时等号成立。这个不等式非常有用，以后会经常见面！  

### 四、不等式性质：运算中的不变性  
类比等式性质，不等式有哪些“脾气”呢？  
- **对称性**：如果 $a > b$，反过来 $b < a$，就像“你比我高，我就比你矮”。  
- **传递性**：如果 $a > b$ 且 $b > c$，那么 $a > c$，和“甲比乙高，乙比丙高，所以甲比丙高”一样。  
- **可加性**：不等式两边加同一个数，方向不变，比如 $3 > 1$，加5后 $8 > 6$，还是成立的。  
- **可乘性**：乘正数方向不变，乘负数要“反转”，比如 $3 > 2$，乘2得 $6 > 4$，但乘-1就得 $-3 < -2$，这点一定要注意！  


#### 例题与练习（2分钟）

### 例题：作差法比较大小  
比较 $(x+3)(x+7)$ 和 $(x+4)(x+6)$ 的大小。  
解：作差得 $(x²+10x+21) - (x²+10x+24) = -3 < 0$，所以 $(x+3)(x+7) < (x+4)(x+6)$。  


#### 总结（2分钟）  
今天我们学了什么？  
1. **不等关系**：用不等式表示生活中的限制条件，比如限速、成分要求。  
2. **作差法**：比较两数大小的核心方法，差与0的关系决定大小。  
3. **重要不等式**：$a² + b² \geq 2ab$，等号成立当且仅当 $a = b$。  
4. **不等式性质**：对称性、传递性、可加性、可乘性等，尤其注意乘负数时方向改变。  

记住哦，不等式的性质是解不等式的“规则”，就像游戏中的关卡规则，掌握好才能顺利通关。课后请大家完成课本练习，思考：如果 $a > b$，那么 $a³$ 和 $b³$ 谁大谁小呢？我们下节课继续探索不等式的应用！今天的课就到这里，下课！  



## 2.2 基本不等式  



### 知识点总结  
1. **基本不等式的定义与推导**  
   - **形式**：若 $a > 0$，$b > 0$，则 $\sqrt{ab} \leq \frac{a+b}{2}$，当且仅当 $a = b$ 时等号成立。  
   - **意义**：两个正数的算术平均数 $\frac{a+b}{2}$ 不小于它们的几何平均数 $\sqrt{ab}$。  
   - **推导**：由 $a^2 + b^2 \geq 2ab$ 替换 $a$ 为 $\sqrt{a}$、$b$ 为 $\sqrt{b}$ 得到，或通过完全平方公式 $(\sqrt{a} - \sqrt{b})^2 \geq 0$ 证明。  

2. **几何解释**  
   - 以圆的直径 $AB = a + b$，圆心为中点，弦 $CD = \sqrt{ab}$，则 $CD \leq$ 半径 $\frac{a+b}{2}$，当且仅当 $a = b$ 时弦为半径。  

3. **应用：求最值问题**  
   - **积定和最小**：若 $ab = P$（定值），则 $a + b \geq 2\sqrt{P}$，当 $a = b$ 时取最小值 $2\sqrt{P}$。  
   - **和定积最大**：若 $a + b = S$（定值），则 $ab \leq \frac{S^2}{4}$，当 $a = b$ 时取最大值 $\frac{S^2}{4}$。  
   - **条件**：一正（$a, b > 0$）、二定（和或积为定值）、三相等（等号能取到）。  


### “基本不等式”十分钟逐字讲稿  

#### 引入（1分钟）  
同学们好！上节课我们学习了不等式的性质，还认识了重要不等式 $a^2 + b^2 \geq 2ab$。今天咱们要探索它的“特殊版本”——**基本不等式**，它可是解决最值问题的“利器”哦！比如，如何用最短的篱笆围出最大的菜园，就靠它啦！（板书课题：2.2 基本不等式）  


#### 知识点讲解（5分钟）  
### 一、从重要不等式到基本不等式  
还记得吗？对于任意实数 $a, b$，有 $a^2 + b^2 \geq 2ab$，当且仅当 $a = b$ 时等号成立。现在如果 $a, b$ 都是正数，我们用 $\sqrt{a}$ 和 $\sqrt{b}$ 代替原来的 $a, b$，会发生什么呢？代入后得到：  
\[
(\sqrt{a})^2 + (\sqrt{b})^2 \geq 2\sqrt{a}\sqrt{b} \quad \Rightarrow \quad a + b \geq 2\sqrt{ab},
\]  
两边除以2，就是基本不等式：$\frac{a+b}{2} \geq \sqrt{ab}$（板书）。这里 $\frac{a+b}{2}$ 叫算术平均数，$\sqrt{ab}$ 叫几何平均数，所以基本不等式的意思是：**两个正数的算术平均数不小于几何平均数**。  

### 二、几何直观：圆里的不等式  
看这幅图（指黑板画图）：圆的直径 $AB = a + b$，圆心是中点，半径就是 $\frac{a+b}{2}$。点 $C$ 分直径为 $a$ 和 $b$，过 $C$ 作垂直于直径的弦 $CD$，根据相似三角形，$CD = \sqrt{ab}$。因为弦 $CD$ 不会超过半径，所以 $\sqrt{ab} \leq \frac{a+b}{2}$，当 $C$ 与圆心重合（即 $a = b$）时，等号成立。是不是很直观？  

### 三、最值应用：积定和最小，和定积最大  
基本不等式的“魔法”在于求最值：  
1. **如果两个正数的积是定值**（比如 $ab = 100$），那么它们的和有最小值 $2\sqrt{ab}$，当且仅当两数相等时取到最小值。  
2. **如果两个正数的和是定值**（比如 $a + b = 36$），那么它们的积有最大值 $\left(\frac{a+b}{2}\right)^2$，同样在两数相等时取到最大值。  
记住三个条件：**一正、二定、三相等**，缺一不可哦！  


#### 例题与练习（2分钟）  
### 例题：求最小值  
例1：已知 $x > 0$，求 $x + \frac{1}{x}$ 的最小值。  
解：因为 $x$ 和 $\frac{1}{x}$ 都是正数，且积为 $x \cdot \frac{1}{x} = 1$（定值），所以根据基本不等式：  
\[
x + \frac{1}{x} \geq 2\sqrt{x \cdot \frac{1}{x}} = 2,
\]  
当且仅当 $x = \frac{1}{x}$ 即 $x = 1$ 时，等号成立。所以最小值是2。  

### 小练习  
1. 已知 $x, y > 0$，且 $x + y = 10$，求 $xy$ 的最大值。（答案：当 $x = y = 5$ 时，$xy$ 最大为25）  
2. 思考：如果 $x < 0$，还能用基本不等式求 $x + \frac{1}{x}$ 的最值吗？为什么？（不能，因为不满足“一正”条件）  


#### 总结（2分钟）  
今天我们学了什么？  
1. **基本不等式**：$\frac{a+b}{2} \geq \sqrt{ab}$（$a, b > 0$），等号当且仅当 $a = b$ 时成立。  
2. **几何意义**：圆中弦长不超过半径，直观体现不等式关系。  
3. **最值应用**：积定和最小，和定积最大，注意“一正二定三相等”。  

课后请大家用基本不等式解决：用20cm的铁丝围成矩形，怎么围面积最大？（提示：设长和宽为 $x, y$，则 $x + y = 10$，求 $xy$ 最大值）下节课我们会用基本不等式解决更多实际问题，比如造价最低、容积最大等问题。今天的课就到这里，下课！  


## 2.3 二次函数与一元二次方程、不等式  


### **知识点总结**  
1. **一元二次不等式**：形如$ax^2 + bx + c > 0$或$< 0$（$a \neq 0$）.   
2. **解法（函数观点）**：  
   - 求对应方程$ax^2 + bx + c = 0$的根（判别式$\Delta = b^2 - 4ac$）.   
   - 画二次函数$y = ax^2 + bx + c$的图象，根据图象与x轴的位置关系确定解集：  
     - $\Delta > 0$：解集为两根之外或之间（看开口方向）.   
     - $\Delta = 0$：解集为全体实数（除顶点）或空集.   
     - $\Delta < 0$：解集为全体实数或空集.   
3. **步骤**：化正（二次项系数为正）→ 求根 → 画图象 → 写解集.   


### **十分钟讲稿：2.3 二次函数与一元二次方程、不等式**  

**引入（2分钟）**  
同学们，之前我们用一次函数解一元一次不等式，今天用二次函数解一元二次不等式. 比如：矩形边长$x$，面积$(12 - x)x > 20$，整理得$x^2 - 12x + 20 < 0$. 怎么解呢？结合二次函数图象来看.   

**知识点讲解（4分钟）**  
首先，一元二次不等式的一般形式是$ax^2 + bx + c > 0$（$a \neq 0$）. 解法分三步：  
1. **化正**：若$a < 0$，两边乘-1，不等号变向（如$-x^2 + 2x - 3 > 0$化为$x^2 - 2x + 3 < 0$）.   
2. **求根**：解方程$ax^2 + bx + c = 0$，用求根公式或因式分解，判别式 $\Delta$ 决定根的个数.   
3. **画图象写解集**：开口向上时，图象在x轴上方对应$> 0$，下方对应$< 0$（板书三种 $\Delta$ 的情况表格）.   

比如例1：$x^2 - 5x + 6 > 0$，解方程得根2和3，图象开口向上，所以解集是$x < 2$或$x > 3$.   

**例题与练习（3分钟）**  
例2：$9x^2 - 6x + 1 > 0$，$\Delta=0$，根为$\frac{1}{3}$，图象开口向上，仅在顶点处等于0，所以解集是$x \neq \frac{1}{3}$.   

练习：解$-x^2 + 4x - 4 < 0$，先化正为$x^2 - 4x + 4 > 0$，即$(x - 2)^2 > 0$，解集是$x \neq 2$（引导学生步骤）.   

再看实际问题：摩托车生产收益$y = -20x^2 + 2200x > 60000$，整理得$x^2 - 110x + 3000 < 0$，根50和60，解集50 < x < 60，所以生产51-59辆（强调实际意义）.   

**总结（1分钟）**  
今天学会了用二次函数图象解一元二次不等式，关键是求根和看开口方向. 记住：化正→求根→定解集，$\Delta$ 的三种情况对应不同的解集形式. 这就是函数、方程、不等式的“三位一体”思想，以后会经常用到.
