# 第三章 函数的概念与性质

## 3.1 函数的概念及其表示

### 知识点总结
1. **函数的概念**：设$A$、$B$是非空实数集，若对集合$A$中任意数$x$，按确定对应关系$f$，在集合$B$中有唯一确定的数$y$与之对应，则称$f:A→B$为从集合$A$到集合$B$的函数，记作$y = f(x),x∈A$. 其中$x$是自变量，$A$是定义域，$\{f(x)|x∈A\}$是值域 ，且值域是集合$B$的子集. 
2. **函数的构成要素**：定义域、对应关系和值域. 两个函数定义域相同且对应关系完全一致时，它们是同一个函数. 
3. **区间的概念**：设$a$，$b$是实数，且$a < b$. 满足$a≤x≤b$的实数$x$的集合为闭区间$[a,b]$；满足$a < x < b$的实数$x$的集合为开区间$(a,b)$；满足$a≤x < b$或$a < x≤b$的实数$x$的集合为半开半闭区间$[a,b)$或$(a,b]$ . 实数集$R$可表示为$(-∞,+∞)$，还有$[a,+∞)$、$(a,+∞)$、$(-∞,b]$、$(-∞,b)$等区间表示形式. 
4. **函数的表示法**：解析法（用解析式表示变量对应关系）、列表法（列出表格表示变量对应关系）、图象法（用图象表示变量对应关系）. 还有分段函数，如$y=\begin{cases}-x,x<0\\x,x\geq0\end{cases}$ ，生活中出租车计费、个人所得税纳税额等问题常用分段函数描述. 

### “函数的概念及其表示”十分钟逐字稿
同学们好！在正式开始今天的课程之前，老师先和大家聊一聊生活中的一些现象. 大家有没有注意到，像高铁运行时，它行进的路程会随着运行时间的变化而变化；去超市买东西，商品的总价会随着购买数量的改变而改变. 这些现象都有一个共同点，就是一个量的变化会引起另一个量的变化，而这种变量之间的对应关系，我们可以用函数来描述. 函数在数学中可是非常重要的内容，从今天开始，咱们就深入学习函数的概念及其表示. （板书课题：3.1函数的概念及其表示）

我们先来看几个具体的问题. 某“复兴号”高速列车加速到350km/h后匀速运行半小时，列车行进的路程$s$与运行时间$t$的关系是$s = 350t$. 这里$t$和$s$是两个变量，对于$t$每一个确定的值，$s$都有唯一确定的值与之对应，所以$s$是$t$的函数. 但是要注意，$t$的变化范围是数集$A_1 = \{t|0≤t≤0.5\}$，$s$的变化范围是数集$B_1 = \{s|0≤s≤175\}$ . 也就是说，函数不仅要有对应关系，还要明确变量的取值范围. 

再看，某电气维修公司工人工资$w$与工作天数$d$的关系为$w = 350d$，$d$的范围是$A_2 = \{1,2,3,4,5,6\}$ ，$w$的范围是$B_2 = \{350,700,1050,1400,1750,2100\}$，$w$也是$d$的函数. 

通过这些例子，我们来归纳一下函数的概念. 一般地，设$A$、$B$是非空的实数集，如果对于集合$A$中的任意一个数$x$，按照某种确定的对应关系$f$，在集合$B$中都有唯一确定的数$y$和它对应，那么就称$f:A→B$为从集合$A$到集合$B$的一个函数，记作$y = f(x),x∈A$. $x$是自变量，$x$的取值范围$A$是定义域，与$x$值对应的$y$值是函数值，函数值的集合$\{f(x)|x∈A\}$是值域，而且值域是集合$B$的子集. 

比如我们熟悉的一次函数$y = ax + b(a≠0)$，定义域是$R$，值域也是$R$；二次函数$y = ax^2 + bx + c(a≠0)$，定义域是$R$ ，当$a > 0$时，值域是$B = \{y|y≥\frac{4ac - b^2}{4a}\}$ ，当$a < 0$时，值域是$B = \{y|y≤\frac{4ac - b^2}{4a}\}$. 

研究函数时，我们经常会用到区间的概念. 设$a$，$b$是两个实数，而且$a < b$. 满足$a≤x≤b$的实数$x$的集合叫做闭区间，表示为$[a,b]$ ；满足$a < x < b$的实数$x$的集合叫做开区间，表示为$(a,b)$ ；满足$a≤x < b$或$a < x≤b$的实数$x$的集合叫做半开半闭区间，分别表示为$[a,b)$、$(a,b]$. 实数集$R$可以用区间表示为$(-∞,+∞)$. 

接下来，我们了解一下函数的表示法. 在初中我们就接触过函数的三种表示法：解析法、列表法和图象法. 解析法就是用解析式表示两个变量之间的对应关系，像前面列车路程和时间的关系$s = 350t$；列表法是列出表格来表示对应关系，比如给出不同年份的恩格尔系数；图象法是用图象表示对应关系，比如空气质量指数随时间的变化图. 

我们来看一个具体的例子，某种笔记本单价是5元，买$x(x∈\{1,2,3,4,5\})$个笔记本需要$y$元. 用解析法表示这个函数就是$y = 5x,x∈\{1,2,3,4,5\}$ ；列表法可以列出表格，清楚地看到笔记本数量和钱数的对应；图象法画出来就是几个离散的点. 这三种表示法各有特点，解析法简洁准确，能清晰展示变量关系；列表法直观具体，数据一目了然；图象法形象直观，能直观反映函数的变化趋势. 

还有一种特殊的函数叫做分段函数. 比如函数$y = |x|$，它可以写成$y=\begin{cases}-x,x<0\\x,x\geq0\end{cases}$ . 生活中有很多这样的例子，像出租车的计费，在不同里程段收费标准不同，就可以用分段函数来描述. 

下面我们通过例题来巩固一下这些知识. 已知函数$f(x)=\sqrt{x + 3}+\frac{1}{x + 2}$，求它的定义域. 要使根式有意义，$x + 3≥0$ ，即$x≥ - 3$；要使分式有意义，$x + 2≠0$ ，即$x≠ - 2$. 所以定义域就是$[ - 3, - 2)∪( - 2,+∞)$. 

再看，判断函数$y = (\sqrt{x})^2$与函数$y = x$是不是同一个函数. $y = (\sqrt{x})^2$的定义域是$x≥0$，而$y = x$的定义域是$R$，虽然它们的对应关系在$x≥0$时相同，但定义域不同，所以不是同一个函数. 


通过今天的学习，我们知道了函数是描述变量间对应关系的数学模型，它由定义域、对应关系和值域构成. 我们还学习了区间的概念以及函数的三种表示法，包括分段函数. 函数在我们生活和数学学习中都非常重要，希望大家课后认真复习，多做练习，加深对函数的理解. 今天的课就到这里，下课！ 


## 3.2 函数的基本性质

### 知识点总结
1. **函数的单调性**：设函数$f(x)$的定义域为$D$，区间$I\subseteq D$。若对于任意的$x_1$，$x_2\in I$，当$x_1\lt x_2$时，都有$f(x_1)\lt f(x_2)$，则称函数$f(x)$在区间$I$上单调递增；若都有$f(x_1)\gt f(x_2)$，则称函数$f(x)$在区间$I$上单调递减。函数在某区间单调递增或单调递减，该区间就是函数的单调区间。函数的单调性是对定义域内某个区间而言的。
2. **函数的最值**：设函数$y = f(x)$的定义域为$D$，如果存在实数$M$满足：对于任意$x\in D$，都有$f(x)\leq M$，且存在$x_0\in D$，使得$f(x_0)=M$，那么$M$是函数$y = f(x)$的最大值；同理，如果存在实数$m$满足：对于任意$x\in D$，都有$f(x)\geq m$，且存在$x_0\in D$，使得$f(x_0)=m$，那么$m$是函数$y = f(x)$的最小值 。
3. **函数的奇偶性**：设函数$f(x)$的定义域为$D$，如果对于任意$x\in D$，都有$-x\in D$，且$f(-x)=f(x)$，那么函数$f(x)$就叫做偶函数，偶函数的图象关于$y$轴对称；如果对于任意$x\in D$，都有$-x\in D$，且$f(-x)= - f(x)$，那么函数$f(x)$就叫做奇函数，奇函数的图象关于原点对称。奇偶性是函数在定义域上的整体性质，判断函数奇偶性要先明确其定义域。

### “函数的基本性质”十分钟逐字讲稿
同学们好！之前我们学习了函数的概念和表示方法，知道函数就像一个神奇的“转换器”，能把自变量变成对应的函数值。今天，我们来探索函数身上隐藏的一些“秘密武器”——函数的基本性质。这些性质可以帮助我们更好地了解函数的行为，就像了解一个人的性格特点一样。（板书课题：3.2函数的基本性质）

在正式开始前，大家先观察一下老师展示的这些函数图象（展示包含不同函数图象的图片），看看能不能发现它们有哪些不同的变化趋势呢？有的图象是上升的，有的是下降的，还有的好像有一些对称的特点。这些就是我们今天要研究的函数性质，分别是单调性、最值和奇偶性。

我们先来看函数的单调性。回忆一下二次函数$f(x)=x^2$，大家在草稿纸上画出它的图象。（稍作停顿，给学生时间画图）可以看到，图象在$y$轴左侧是下降的，这意味着当$x\leq0$时，$x$的值越来越大，$y$的值却越来越小。用数学语言来说，就是任意取$x_1$，$x_2\in(-\infty,0]$ ，当$x_1\lt x_2$时，都有$f(x_1)\gt f(x_2)$，这时我们就说函数$f(x)=x^2$在区间$(-\infty,0]$上是单调递减的。再看$y$轴右侧，图象是上升的，也就是当$x\geq0$时，$x$增大，$y$也增大。即任意取$x_1$，$x_2\in[0,+\infty)$ ，当$x_1\lt x_2$时，$f(x_1)\lt f(x_2)$，函数$f(x)=x^2$在区间$[0,+\infty)$上是单调递增的。

一般地，设函数$f(x)$的定义域为$D$，区间$I\subseteq D$。如果对于区间$I$内任意的$x_1$，$x_2$ ，当$x_1\lt x_2$时，都有$f(x_1)\lt f(x_2)$，那么函数$f(x)$在区间$I$上单调递增；如果都有$f(x_1)\gt f(x_2)$，则函数$f(x)$在区间$I$上单调递减。函数在某个区间上单调递增或单调递减，这个区间就是它的单调区间。比如说一次函数$f(x)=kx + b$（$k\neq0$） ，当$k\gt0$时，函数是增函数；当$k\lt0$时，函数是减函数。大家可以自己推导一下哦。

接着，我们来探讨函数的最值。还是以二次函数$f(x)=x^2$为例，观察图象可以发现，图象有一个最低点，也就是当$x = 0$时，$f(x)$取得最小值$0$ 。一般地，设函数$y = f(x)$的定义域为$D$ ，如果存在实数$M$，对于任意$x\in D$，都有$f(x)\leq M$，并且存在$x_0\in D$，使得$f(x_0)=M$，那么$M$就是函数$y = f(x)$的最大值；反过来，如果存在实数$m$，对于任意$x\in D$，都有$f(x)\geq m$，且存在$x_0\in D$，使得$f(x_0)=m$，$m$就是函数$y = f(x)$的最小值。比如说烟花距地面高度$h(t)= - 4.9t^2 + 14.7t + 18$，通过二次函数的知识，我们能求出它的最大值，也就是烟花爆裂的最佳时刻和距地面的高度。

最后，我们来认识函数的奇偶性。画出函数$f(x)=x^2$和$g(x)=2 - |x|$的图象（老师在黑板上简单画出图象或展示图片），大家看，这两个函数的图象都关于$y$轴对称。我们来探究一下，对于函数$f(x)=x^2$ ，当$x$取一对相反数时，比如$x = 3$和$x = - 3$ ，$f(3)=9$ ，$f(-3)=9$，也就是$f(-x)=f(x)$，这样的函数就是偶函数。一般地，如果函数$f(x)$的定义域为$D$，对于任意$x\in D$，都有$-x\in D$，且$f(-x)=f(x)$，那么$f(x)$就是偶函数。再看函数$f(x)=x$和$g(x)=\frac{1}{x}$的图象，它们关于原点成中心对称图形。对于函数$f(x)=x$，当$x$取一对相反数时，$f(-3)= - 3$ ，$f(3)=3$ ，$f(-x)= - f(x)$，这样的函数就是奇函数。即函数$f(x)$的定义域为$D$，对于任意$x\in D$，都有$-x\in D$，且$f(-x)= - f(x)$，$f(x)$就是奇函数。

下面我们通过例题来巩固一下这些知识。

例1：判断函数$f(x)=3x + 2$的单调性。根据单调性的定义，设$x_1$，$x_2\in R$，且$x_1\lt x_2$ ，计算$f(x_1)-f(x_2)=(3x_1 + 2)-(3x_2 + 2)=3(x_1 - x_2)$ 。因为$x_1\lt x_2$，所以$x_1 - x_2\lt0$ ，又因为$3\gt0$，所以$3(x_1 - x_2)\lt0$，即$f(x_1)\lt f(x_2)$ ，所以函数$f(x)=3x + 2$是增函数。

例2：判断函数$f(x)=\frac{1}{x^2}$的奇偶性。首先，函数的定义域为$\{x|x\neq0\}$ ，对于任意$x\in\{x|x\neq0\}$ ，都有$-x\in\{x|x\neq0\}$ ，且$f(-x)=\frac{1}{(-x)^2}=\frac{1}{x^2}=f(x)$，所以函数$f(x)=\frac{1}{x^2}$是偶函数。

通过今天的学习，我们知道了函数有单调性、最值和奇偶性这些重要性质。单调性描述了函数的增减变化，最值让我们知道函数能取到的最大或最小值，奇偶性体现了函数图象的对称特点。这些性质帮助我们从不同角度认识函数，就像戴上了多副不同的“眼镜”去观察函数一样。课后大家要认真复习今天的内容，多做练习题，加深对函数基本性质的理解。下节课我们会继续深入研究函数的其他相关知识。今天的课就到这里，下课！ 

## 3.3 幂函数

### 知识点总结
1. **幂函数的定义**：一般地，函数$y = x^{\alpha}$（$x$是自变量，$\alpha$是常数）叫做幂函数。像$y = x$（$\alpha = 1$）、$y = x^{2}$（$\alpha = 2$）、$y = x^{3}$（$\alpha = 3$）、$y = x^{\frac{1}{2}}$（$\alpha=\frac{1}{2}$ ）、$y = x^{-1}$（$\alpha = - 1$）等都是幂函数。
2. **幂函数的图象与性质**：研究$\alpha = 1,2,3,\frac{1}{2}, - 1$时幂函数的图象与性质。这些函数图象都过点$(1,1)$ ；$y = x$、$y = x^{3}$、$y = x^{-1}$是奇函数，$y = x^{2}$是偶函数；在区间$(0, +\infty)$上，$y = x$、$y = x^{2}$、$y = x^{3}$ 、$y = x^{\frac{1}{2}}$单调递增，$y = x^{-1}$单调递减；在第一象限内，$y = x^{-1}$的图象向上与$y$轴无限接近，向右与$x$轴无限接近。
3. **幂函数性质的应用**：利用幂函数的单调性比较大小。例如，对于幂函数$y = x^{3}$，因为其在$R$上单调递增，所以当$a > b$时，$a^{3} > b^{3}$。还可以根据幂函数的性质和定义来判断函数的奇偶性、证明函数的单调性等。

### “幂函数”十分钟逐字讲稿
同学们好！在前面的学习中，我们已经认识了函数这个大家族，学习了函数的概念、表示方法以及函数的一些基本性质，像单调性、奇偶性和最值。今天，我们要在函数这个大家族里认识一位新成员——幂函数。（板书课题：3.3幂函数）

大家先来看几个生活中的例子。如果张红以1元/kg的价格买蔬菜，买了$w$kg，她要支付的钱$p = w$元，$p$是$w$的函数；正方形边长是$a$，面积$S = a^{2}$ ，$S$是$a$的函数；立方体棱长为$b$，体积$V = b^{3}$ ，$V$是$b$的函数；正方形场地面积为$S$ ，边长$c=\sqrt{S}=S^{\frac{1}{2}}$ ，$c$是$S$的函数；某人$t$秒骑车行进1km，平均速度$v=\frac{1}{t}=t^{-1}$ ，$v$是$t$的函数。

观察这些函数的解析式，它们都有一个共同的特点，都是以幂的底数为自变量，幂的指数是常数。像这样的函数$y = x^{\alpha}$，我们就把它叫做幂函数，这里$x$是自变量，$\alpha$是常数。这节课，我们主要研究$\alpha = 1,2,3,\frac{1}{2}, - 1$这几种情况。

那怎么研究幂函数呢？我们可以先求出函数的定义域，再画出函数的图象，然后借助图象和解析式来讨论函数的值域、单调性、奇偶性这些性质。现在，我们在同一坐标系中画出$y = x$，$y = x^{2}$，$y = x^{3}$，$y = x^{\frac{1}{2}}$和$y = x^{-1}$这几个幂函数的图象（老师在黑板上画草图或者借助多媒体展示准确图象）。

大家观察图象，结合函数解析式，把发现的结论填到这个表格里（展示表格，引导学生思考填写）。通过观察我们发现，这些函数图象都过点$(1,1)$；$y = x$ 、$y = x^{3}$ 、$y = x^{-1}$这三个函数是奇函数，$y = x^{2}$是偶函数；在区间$(0, +\infty)$上，$y = x$ 、$y = x^{2}$ 、$y = x^{3}$ 、$y = x^{\frac{1}{2}}$是单调递增的，$y = x^{-1}$是单调递减的；在第一象限里，$y = x^{-1}$的图象向上无限靠近$y$轴，向右无限靠近$x$轴。

下面我们来看一个例题，证明幂函数$f(x)=\sqrt{x}=x^{\frac{1}{2}}$是增函数。首先，它的定义域是$[0, +\infty)$ 。对于任意的$x_{1}$，$x_{2} \in [0, +\infty)$ ，并且$x_{1} < x_{2}$ ，我们来比较$f(x_{1})$和$f(x_{2})$的大小。$f(x_{1}) - f(x_{2})=\sqrt{x_{1}} - \sqrt{x_{2}}$，分子分母同时乘以$\sqrt{x_{1}}+\sqrt{x_{2}}$进行变形，得到$\frac{x_{1}-x_{2}}{\sqrt{x_{1}}+\sqrt{x_{2}}}$ 。因为$x_{1} - x_{2} < 0$ ，而$\sqrt{x_{1}}+\sqrt{x_{2}}>0$ ，所以$f(x_{1}) - f(x_{2}) < 0$ ，也就是$f(x_{1}) < f(x_{2})$ ，这就证明了$f(x)=\sqrt{x}$是增函数。
