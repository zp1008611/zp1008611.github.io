家长质疑：
    - 首先主动和家长进行沟通，倾听家长的意见和建议。

    - 最后与家长保持联系，定期召开家长会，与家长探讨更好的教育方法，共同为孩子的成长而努力。

## 1 学生管理类

- 学生犯错
    - 发生在课堂：（打架）
        - 上课时，为了不影响课堂秩序，制止学生的行为，如果后面学生还在课堂上犯错，则让班长先把学生先带到办公室。
        - 下课后，询问学生这样做的原因，
            - 如果是因为原因1，我会...
            - 如果是因为原因2，我会...
            - 但不管因为什么原因，都要进行批评教育
        - 后续继续观察学生表现，如果做得好表扬，如果做得不好提醒
    
    - 不发生在课堂：（不交作业）
        - 对学生：询问学生这样做的原因，
            - 如果是因为原因1，我会...
            - 如果是因为原因2，我会...
            - 但不管因为什么原因，都要进行批评教育
        - 对家长：和家长及时沟通学生的犯错情况，让家长帮忙督促学生
        - 对自己：将学生的犯错行为记入教学反思日志，并反思学生犯错的行为是否与自己对学生的管理不严格导致，今后怎么做

- 学生没犯错（学生哭）
    - 处理当下状况（安慰）
    - 事后询问学生这样做的原因
        - 如果是因为原因1，我会...
        - 如果是因为原因2，我会...
    - 后续观察学生的状态，并反思学生出现这种行为是否与自己对学生的心理关怀较少，今后怎么做


## 2 家长沟通

- 不涉及学生（家长质疑老师、家长给老师送礼）
    - 聆听家长的想法，表示抱歉/感谢
    - 向家长解释（自己的原因/学校规定）
    - 反思自己，反思发生这件事发生的主要原因是否与自己在家校沟通有所欠缺，今后怎么做





- 涉及学生（家长说老师没看好孩子，家长管教孩子的方式有问题）
    - 与家长沟通：安抚家长情绪
    - 与学生沟通
    - 自己：观察后续，事后反思（是不是对学生关心不够），今后怎么做

## 6 时政热点题

- 什么是大先生？
    - 大先生是指能够为学生传道、授业、解惑的教育者们。
    - 做“大先生”的核心要求：立德树人、专业卓越、教育情怀、终身学习
    - 如何做新时代的大先生：我们要有坚定的理想信念，不断地提高专业水平，严谨治学、求实创新，并把立德树人作为根本任务，培养肩负中华民族伟大复兴的下一代

- 教育家精神是什么？你如何理解？
    - 心有大我、至诚报国的理想信念
    - 言为士则、行为世范的道德情操
    - 启智润心、因材施教的育人智慧
    - 勤学笃行、求是创新的躬耕态度
    - 乐教爱生、甘于奉献的仁爱之心
    - 胸怀天下、以文化人的弘道追求

- 三有青年
    - 有理想、有本领、有担当的青年

- 四有好老师
    - 有理想信念、有道德情操、有扎实学识、有仁爱之心的老师


- 四个引路人
    - 做学生锤炼品格的引路人，做学生学习知识的引路人，做学生创新思维的引路人，做学生奉献祖国的引路人



- 四个相统一
    - 坚持教书与育人相统一
    - 坚持言传和身教相统一
    - 坚持潜心问道和关注社会相统一
    - 坚持学术自由和学术规范相统一

- 四个自信
    - 道路自信、理论自信、制度自信、文化自信

- 社会主义核心价值观    
    - 富强民主文明和谐（国家层面的价值目标）
    - 自由平等公正法治（社会层面的价值取向）
    - 爱国敬业诚信友善（公民个人层面的价值准则）

- 双减和双增
    - 双减：减轻义务阶段学生的作业负担，减少学生的校外培训负担
    - 双增：给学生增加更多参与户外活动的机会，校外培训机构增加体育和美育培训机会
    - 提高学校教学质量，严格管理校外培训机构



- 四好学生
    - 有理想、有道德、有文化、有纪律的学生
