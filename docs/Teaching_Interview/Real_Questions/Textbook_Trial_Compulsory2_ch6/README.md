## 6.2.1 向量的加法运算


同学们，在之前的学习中，我们已经认识了向量的基本概念，知道向量是既有大小又有方向的量. 那大家有没有想过，向量是否能像实数一样进行四则运算呢？这就是我们接下来要探讨的主题，首先我们先来思考（板书：向量的加法运算）

在之前的学习中，我们知道位移、力都是向量，那么今天老师利用位移的合成以及力的合成来探讨一下向量是如何相加的. 

首先，我们先来看位移的合成，如果我们有一个质点从 $A$ 经过点 $B$ 到点 $C$，有同学知道这个质点的位移是多少了？好，请这位同学回答一下，好的，你说通过物理学知识可以知道，质点从 $A$ 经过点 $B$ 到点 $C$的位移是 向量 $\overrightarrow{AC}$ ，没错，回答得非常好，那么就是质点从$A$到$B$到$C$两次位移结果的合成就等于从$A$直接到$C$的位移. 但是这种观察口述的方法对于研究来说非常不简洁，因此数学家们将这种向量合成的现象抽象成向量加法的运算，从而能够以代数的形式来描述向量合成，我们将两个向量的合成向量称为和向量，抽象后的向量加法表示为 $\overrightarrow{AB}+\overrightarrow{BC}=\overrightarrow{AC}$. 我们再来看看在位移合成中，前一个向量的终点是后一个向量的起点，和向量是从第一个向量的起点指向最后一个向量的终点下面，我们将这种求和向量的方法称为向量加法的三角形法则，下面我们给出严格定义：对于两个非零向量 $\vec{a}$ 、 $\vec{b}$ ，我们在平面内任取一点 $A$，作 $\overrightarrow{AB}=\vec{a}$ ， $\overrightarrow{BC}=\vec{b}$ ，则向量 $\overrightarrow{AC}$ 就是 向量 $\vec{a}$ 与  向量 $\vec{b}$ 的和，记作 $\vec{a} + \vec{b}=\overrightarrow{AC}$. 


下面我们再来看力的合成问题. 假设一个物体受到两个力 $F_1$ 和 $F_2$ 的作用，通过物理学知识，我们知道合力 $F$ 是以这两个力为邻边的平行四边形的对角线. 可以看到两个向量 $F_1$, $F_2$ 的起点相同，和向量 $F$ 是从公共起点出发的对角线向量，我们将这种求和向量的方法称为向量加法的平行四边形法则，下面我们给出严格定义：以同一点O为起点的两个已知向量 $\vec{a}$ 、 $\vec{b}$ ，以 $\overrightarrow{OA}$、$\overrightarrow{OB}$ 为邻边作平行四边形 $OACB$，则以O为起点的对角线向量 $\overrightarrow{OC}$ 就是 $\vec{a}$ 与 $\vec{b}$ 的和, 记作 $\vec{a} + \vec{b} = \overrightarrow{OC}$.

例1：图6.2.5，已知向量 $\vec{a}$ 、 $\vec{b}$ ，用两种方法求作向量 $\vec{a} + \vec{b}$ . 

**作法1（三角形法则）**：在平面内任取一点O，作 $\overrightarrow{OA} = \vec{a}$ ，再以A为起点作 $\overrightarrow{AB} = \vec{b}$ ，则 $\overrightarrow{OB} = \vec{a} + \vec{b}$ . 

**作法2（平行四边形法则）**：在平面内任取一点O，作 $\overrightarrow{OA} = \vec{a}$ ， $\overrightarrow{OB} = \vec{b}$ ，以OA、OB为邻边作平行四边形OACB，连接OC，则 $\overrightarrow{OC} = \vec{a} + \vec{b}$ . 

这两种计算法则本质上是一致的，它们都是向量$a$，$b$进行平移后，向量加法的几何表示方法.
