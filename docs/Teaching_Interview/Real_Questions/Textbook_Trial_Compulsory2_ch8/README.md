## 8.4.2 空间点、直线、平面之间的位置关系


- https://www.bilibili.com/video/BV1hW4y1e7ND/?spm_id_from=333.1387.homepage.video_card.click&vd_source=3d4b12fb4a4bfbc98942d43612ae2fb9


同学们，之前我们学习过一些简单的几何图形，比如在平面几何里，研究过点、直线的位置关系。那在广阔的空间中，点、直线、平面之间又有着怎样丰富多样的位置关系呢？就像我们熟悉的教室，它是一个立体空间，里面的墙角线（直线）与地面（平面）、天花板（平面）与墙面（平面），它们的位置关系都很值得探究。再看这个长方体模型（展示长方体模型），它有8个顶点、12条棱、6个面，这些顶点、棱所在直线、面所在平面之间的位置关系更是复杂有趣。今天，我们就一起深入学习空间中直线、平面之间的位置关系，去探索立体几何的奥秘。


在长方体 $ABCD - A'B'C'D'$ 中（结合模型或画出长方体示意图），我们来观察直线间的关系。像直线 $AB$ 与 $DC$，它们在同一个平面 $ABCD$ 内，并且没有公共点，这就是平行直线；直线 $AB$ 与 $BC$ 也在平面 $ABCD$ 内，但它们只有一个公共点 $B$ ，这是相交直线；而直线 $AB$ 与 $CC'$ ，无论怎么找，都找不到一个平面能同时包含它们，像这样不同在任何一个平面内的两条直线，我们就叫做异面直线。所以，空间两条直线的位置关系总共有三种：共面直线（包括相交直线和平行直线）和异面直线。这里要注意，空间中两条直线平行和平面上两条直线平行的意义是一致的，都要满足在同一平面内且不相交。为了更直观地表示异面直线不共面的特点，我们作图时，通常会用一个或两个平面衬托（展示相关异面直线的图形示例） 。


继续观察长方体，直线 $AB$ 与平面 $ABCD$ 有无数个公共点，这时候直线就在平面内；直线 $AA'$ 与平面 $ABCD$ 只有一个公共点 $A$ ，这种情况是直线与平面相交；直线 $A'B'$ 与平面 $ABCD$ 没有公共点，就是直线与平面平行。概括来说，直线与平面的位置关系有且只有这三种：直线在平面内（有无数个公共点）、直线与平面相交（有且只有一个公共点）、直线与平面平行（没有公共点）。当直线与平面相交或平行时，直线不在平面内，也叫做直线在平面外。我们还规定了相应的符号表示，直线 $a$ 与平面 $\alpha$ 相交于点 $A$ ，记作 $a\cap\alpha = A$ ；直线 $a$ 与平面 $\alpha$ 平行，记作 $a\parallel\alpha$ 。在画图表示时，直线 $a$ 在平面 $\alpha$ 内，要把直线 $a$ 画在表示平面 $\alpha$ 的平行四边形内；直线 $a$ 在平面 $\alpha$ 外，应把直线 $a$ 或它的一部分画在表示平面 $\alpha$ 的平行四边形外（结合图形讲解画法）。

还是看长方体，平面 $ABCD$ 与平面 $A'B'C'D'$ 没有公共点，这两个平面就是平行的；平面 $ABCD$ 与平面 $BCC'B'$ 有一条公共直线 $BC$ ，这是两个平面相交的情况。所以，两个平面之间的位置关系有且只有两种：平行（没有公共点）和相交（有一条公共直线）。画两个互相平行的平面时，大家要注意使表示平面的两个平行四边形的对应边平行（展示平行平面的正确画法和错误画法对比示例），平面 $\alpha$ 与平面 $\beta$ 平行，记作 $\alpha\parallel\beta$ 。

### 三、总结（2分钟）
同学们，今天我们学习了空间中直线与直线、直线与平面、平面与平面的位置关系。直线与直线有相交、平行、异面三种关系；直线与平面有在平面内、相交、平行三种关系；平面与平面有平行和相交两种关系。还学习了相关的符号表示和判断异面直线的方法。这些知识是立体几何的基础，在后续学习空间中的平行、垂直关系以及几何体的性质等内容时都会经常用到。大家课后要多观察生活中的立体图形，巩固今天所学知识，试着用今天学的知识去描述它们各部分之间的位置关系。 

## 8.5.2 直线与平面平行，直线与平面平行的判定


同学们好！在之前的学习中，我们认识了空间中直线与平面的多种位置关系，那大家能快速说出有哪些吗？没错，有直线在平面内、直线与平面相交、直线与平面平行。今天，我们就重点来研究直线与平面平行，一起探索如何判定直线与平面平行。 （板书：直线与平面平行）

按照前面学习的直线与平面平行的定义，如果直线和平面没有公共点，我们就说这条直线和这个平面平行。但大家想想，直线可以无限延伸，平面可以无限延展，要直接判断它们有没有公共点是不是不太容易？所以，我们需要找到更简便的判定方法。现在，请同学们教室的门，门扇的两边是平行的。当门扇绕着一边转动时，另一边与墙面有公共点吗？对，没有公共点，而且我们能直观地看出，转动的一边与墙面是平行的。从这个例子中，我们可以总结出直线与平面平行的判定定理：如果平面外一条直线与此平面内的一条直线平行，那么该直线与此平面平行。用符号表示就是 $a\not\subset\alpha$ ， $b\subset\alpha$ ，且 $a\parallel b\Rightarrow a\parallel\alpha$ 。大家注意，这里有三个关键条件：一是直线 $a$ 在平面 $\alpha$ 外；二是直线 $b$ 在平面 $\alpha$ 内；三是直线 $a$ 和直线 $b$ 平行，这三个条件缺一不可。这个定理非常重要，它把判断直线与平面平行这样的空间问题，转化成了判断两条直线平行的平面问题，让我们的判断过程变得更简单。

接下来，我们通过具体的例题来加深对这个定理的理解和运用。看例2（展示例2图形），已知空间四边形 $ABCD$ 中， $E$ 、 $F$ 分别是 $AB$ 、 $AD$ 的中点，要证明 $EF\parallel$ 平面 $BCD$ 。我们来分析一下，要证明直线 $EF$ 与平面 $BCD$ 平行，根据刚才学的判定定理，我们需要在平面 $BCD$ 内找到一条直线与 $EF$ 平行。那大家观察图形，能想到哪条直线呢？对，连接 $BD$ ，因为 $E$ 、 $F$ 分别是 $AB$ 、 $AD$ 的中点，根据三角形中位线定理，我们知道 $EF\parallel BD$ 。同时， $EF$ 不在平面 $BCD$ 内， $BD$ 在平面 $BCD$ 内，这就满足了判定定理的所有条件，所以可以得出 $EF\parallel$ 平面 $BCD$ 。通过这个例题，大家要记住证明直线与平面平行的一般思路：先在平面内找一条直线，再证明已知直线和这条直线平行，最后根据判定定理得出结论。 
 
好啦，同学们，今天我们学习了直线与平面平行的判定。首先我们了解了根据定义判定直线与平面平行的方法，但由于其局限性，我们重点学习了直线与平面平行的判定定理。这个定理告诉我们，平面外一条直线与平面内一条直线平行，那么这条直线就和这个平面平行，用符号表示为 $a\not\subset\alpha$ ， $b\subset\alpha$ ，且 $a\parallel b\Rightarrow a\parallel\alpha$ 。通过例2和练习题，我们学会了运用这个定理证明直线与平面平行。大家课后要认真复习，多做一些相关的练习题，加深对定理的理解和掌握。下节课我们将学习直线与平面平行的性质，希望大家提前预习，思考一下如果一条直线与一个平面平行，会有哪些结论呢？今天的课就到这里，下课！
