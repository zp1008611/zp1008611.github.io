然后下面是我的简历介绍，首先是实习经历，从2024年的寒假到2024年的5月份，我参与了久章智能的动线优化项目，这个项目主要是为了优化客户仓储动线效率，一共有三个部分，分别是需求预测及商品关联度分析、货位优化和拣货路径优化。需求预测及商品关联度分析为货位优化提供数据支持，货位优化的结果直接影响拣货路径的效率，三者形成一个前后依赖的链条，需求预测及商品关联度分析是起点，货位优化是中间环节，最终目标是优化拣货路径，提升仓库作业效率. 我重点参与的部分是需求预测及商品关联度分析和货位优化这两部分. 
- 需求预测部分的重点是需求量预测和商品热度计算. 
    - 需求量预测部分，首先对时间序列进行平稳性检验和纯随机性检验，平稳性检验是检验序列是否为平稳序列，只有序列是平稳序列，才可以直接输给sarima，否则就要进行差分操作；纯随机性检验是检验序列是否是纯随机序列，如果是，那么没有必要进行时序预测；
    - 接着使用sarima预测商品未来30日需求量. 
    - 然后以未来30日需求量，上一个月需求量，今年截止目前需求量的需求量为评分指标，使用熵权法计算指标权重，使用topsis法计算每一种商品的热度评分. 
- 商品关联度分析部分是找出关联商品社群
    - 首先使用fp-growth算法找出频繁集并得出强关联规则和对应置信度，fp-growth最终输出是关联规则，即我们知道买了A商品同时又买B商品的置信度是多少，还不是我们需要的商品关联社群
    - 我们使用Louvain算法寻找商品关联社群. Louvain是一种网络社区检测算法，它是一种贪心算法，首先每个节点每个节点自成一个社区，接着遍历每个节点，计算将其移至相邻节点所在社区后模块度的增量，如果增量大于0，则把节点移到社区里. 我们将关联规则抽象成有向边，置信度作为边的权重，然后使用Louvian算法得到商品关联社群.
- 最后就是货位优化部分
    - 这一部分考虑最小化两个目标函数，第一个目标函数是热度评分权重乘以每一种商品距离拣货台的曼哈顿距离，第二个目标函数是商品关联类间各商品的曼哈顿距离之和，最小化这两个目标函数来实现关联货品紧邻、高热货品距拣货台近的目标. 
    - 问题求解部分
        - 使用两个目标函数的加权和作为适应度
        - 编码使用的数据结构是python的字典，字典的键对应仓位编号，值是对应放置的商品编号和放置的数量.
        - 使用贪心算法构造初始解，即热度高的商品放在距离拣货台近的仓位.
        - 优化使用自适应大规模搜索算法，破坏算子只有一个，就是随机从多个仓位拿出多种商品，修复算子有两个，一个是随机重新分配这些商品，另外一个就是打乱商品后，商品分配优先考虑距离拣货台最近的仓位，设置一个随机数对应接受新解标准，有三种标准：无论好坏，接受新解，只接受变好的解，不接受新解. 动态调整算子权重，好的算子权重增加，差的算子权重降低.
    - 最终将编码解码，得出每种商品放置的仓位

接着是项目介绍

第一个多类型客户需求 CVRPTW 问题是受公司的运输项目启发，比如说有的客户商品只能用冷冻车运输，有的客户商品只能用常温车运输，这就是一个多类型客户需求. 
vrp问题可以用可行路径来描述目标函数和约束，目标函数是选择的可行路径成本之和，约束是每一个客户只能被一条可行路径访问以及所有可行路径之和小于车辆数目，但是枚举所有可行路径并不可行，所以可以使用列生成算法来求解问题. 列生成算法框架下，首先求解一个受限主问题的线性松弛，受限是指可行路径集有限，接着依据对偶值找出检验数为负且最小对应的可行路径（对于这个多需求的vrp问题，可行路径是指满足容量约束、满足时间窗约束、满足车型商品匹配约束、满足起点和终点都是车库的约束的路径），这是一个资源受限基本最短路问题，这里我们使用cspy库中的双向标签搜索算法求解得到这个新的可行路径，然后把新的可行路径加入到受限主问题，再次求解受限主问题线性松弛问题，松弛问题的解可能会是分数解，这里就使用分支定界算法分别求解两个分支对应的受限主问题获取更优的解，优先选择最接近0.5的变量作为分支点. 算法对于每日100到150单的数据在5分钟内可以得出结果. 

第二个项目是一个解决柔性作业车间调度，也是公司对接客户的一个demo项目，柔性车间调度这个问题的复杂度很大（是工件数和机器数的指数级别，(m+n)^{m+n}），所以一般使用元启发式算法求解. 遗传算法编码使用MSOS编码，MSOS 整数编码将解分为机器选择和工序排序，机器选择部分的基因表示工序在可选机器集的顺序编号，机器选择部分的基因表示工序加工顺序）两部分. 
- 对于交叉部分，机器选择部分使用均匀交叉，通过随机选取若干位置并交换父代对应基因组成新的子代基因；工序排序部分使用改进POX交叉，就是先划分工件集，再分别从父代复制对应工件集内的工序顺序、非集内工件顺序从另一父代继承的交叉方法.
- 变异部分，机器选择部分变异就是从工序可用的机器中任选一个，工序排序部分变异就是从编码的全排列中选择适应度较好的一个
- 遗传算法还加入了外部记忆库策略，外部记忆库用于保护精英个体，搜索初期，采用记忆库与种群个体交叉；迭代后期，采用种群内个体交叉，以此避免早熟陷入局部最优.
算法能够有效求解Brandimarte 系列的FJSP的标准算例.

第三个项目是一个比赛项目，比赛目的是预测未来三个月的日最大和最小负荷. 工作以缺失值填充、异常值修复和模型预测三部分组成.
- STL分解后向填充策略是当时我们自己想的策略，比赛方给的数据为2018到2021每隔15分钟的数据，缺失的数据段大多是某一整天的数据. 所以我们基于负荷数据的日相似性来填充数据，对原始负荷数据进行 STL 分解，去除残差项，保留周期项和趋势项，生成新序列数据集 B, 从后往前遍历原始数据集 A，遇到缺失值时，利用数据集B中后一天对应时间点的值乘以 0.9~1.1 的随机数填充.
- 异常值检测使用的是孤立森林方法，它是一种无监督异常检测算法，通过随机分割数据空间来孤立数据点. 其核心假设是：异常数据在数据空间中分布稀疏，更容易被快速孤立（即通过更少的分割次数被划分到单独的子空间），而正常数据因分布密集，需要更多次分割才能被孤立. 对检测出的异常点，用其前一个时间点及前 1、2、3 小时相同时刻点的平均值修正.
- 模型预测部分采用的滚动预测策略，滚动预测就是预测第一个点时，用初始训练集训练 XGBOOST 模型，输入当前点特征得到预测值，然后将预测值和对应特征并入训练集，更新数据集，训练下一个模型来预测下一个点，依次类推，直至完成所有点预测.
然后模型在日最大/最小负荷预测误差分别为 3%、6%. 项目成果物获“泰迪杯”数据挖掘挑战赛全国一等奖.
