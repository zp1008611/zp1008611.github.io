# learning-helper 技能

根据用户提供的网页资料链接，分析内容并生成结构化的学习路线。

## 使用场景

- 发现好的学习资源，想整理成系统的学习路径
- 需要根据多个资料制定学习计划

## 工作流程

### 步骤一：收集 URLs

用户提供 1-3 个学习资源 URL（每行一个，或空格分隔）。

示例：
```
https://example.com/python-tutorial
https://docs.python.org/3/tutorial/
```

### 步骤二：获取内容

使用 WebFetch 工具获取每个 URL 的内容。

### 步骤三：分析内容

分析网页内容，提取：
- 主要主题和知识点
- 章节/模块结构
- 难度层级（入门/进阶/高级）
- 前置知识要求

### 步骤四：生成学习路线

创建结构化的 Markdown 文件，包含：

```markdown
# [主题] 学习路线

## 概述
[简短的主题介绍]

## 学习前提
- [前置知识 1]
- [前置知识 2]

## 学习路径

### 阶段一：[入门]
- [知识点 1]
- [知识点 2]

### 阶段二：[进阶]
- ...

### 阶段三：[高级]
- ...

## 推荐资源
- [资源标题]: [URL]

## 实践建议
- [建议 1]
- [建议 2]
```

### 步骤五：保存文件

文件保存路径：`docs/learning-roadmaps/[主题]/README.md`

例如：`docs/learning-roadmaps/python-advanced/README.md`

## 注意事项

- 优先选择权威、有体系的学习资源（如官方文档、知名教程）
- URL 数量控制在 1-3 个，避免信息过载
- 学习路线需要与现有知识库主题对齐
- 创建后提示用户是否需要添加到 nav
