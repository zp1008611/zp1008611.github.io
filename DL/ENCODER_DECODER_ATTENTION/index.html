    Encoder-Decoder模型, 注意力机制¶

    约 5149 个字 预计阅读时间 17 分钟

    1 Encoder-Decoder模型简介¶

    我们从重新审视语言建模问题开始. 通俗来讲，给定“t - i”个单词，我们希望预测第t个单词. 更正式地说，给定 \(y_{1}, y_{2}, ..., y_{t - 1}\)，我们想要找到：

    \[ y^{*} = \underset{}{\text{argmax}} P(y_{t} | y_{1}, y_{2}, ..., y_{t - 1}) \]

    让我们看看如何使用循环神经网络（RNN）对 \(P(y_{t} | y_{1}, y_{2} ... y_{t - 1})\) 进行建模. 我们将 \(P(y_{t} | y_{1}, y_{2} ... y_{t - 1})\) 简记为 \(P(y_{t} | y_{1}^{t - 1})\).

    我们关注的是 \(P(y_{t} = j | y_{1}, y_{2} ... y_{t - 1})\)，其中 \(j \in V\)，\(V\) 是所有词汇的集合. 使用RNN，我们这样计算：

    \[ P(y_{t} = j | y_{1}^{t - 1}) = \text{softmax}(V s_{t} + c)_{j} \]

    换句话说，我们计算：

    \[ \begin{align*} P(y_{t} = j | y_{1}^{t - 1}) &= P(y_{t} = j | s_{t})\\ &= \text{softmax}(V s_{t} + c)_{j} \end{align*} \]

    注意，循环连接确保了 \(s_{t}\) 包含了关于 \(y_{1}^{t - 1}\) 的信息.

    数据：来自任何大型语料库（如维基百科）的所有句子.

    模型：

    \[ s_{t} = \sigma(W s_{t - 1} + U x_{t} + b)$$ $$P(y_{t} = j | y_{1}^{t - 1}) = \text{softmax}(V s_{t} + c)_{j} \]

    参数：\(U\)、\(V\)、\(W\)、\(b\)、\(c\).

    损失：

    \[ \begin{align*} \mathcal{L}(\theta) &= \sum_{t = 1}^{T} \mathcal{L}_{t}(\theta)\\ \mathcal{L}_{t}(\theta) &= -\log P(y_{t} = \ell_{t} | y_{1}^{t - 1}) \end{align*} \]

    其中，\(\ell_{t}\)是时间步t的真实单词.

    每个时间步的输入是什么呢？它就是我们在前一个时间步预测的单词. 一般来说： \(\(s_{t} = \text{RNN}(s_{t - 1}, x_{t})\)\) \(\(x_{t} = e(v_{j})\)\)

    假设\(j\)是在时间步\(t - 1\)被赋予最大概率的单词的索引，\(x_{t} = e(v_{j})\). \(x_{t}\)本质上是一个表示词汇表中第\(j\)个单词的独热向量\((e(v_{j}))\). 在实际应用中，我们通常使用第\(j\)个单词的预训练词嵌入，而不是独热表示.

    注意，\(s_{0}\)不是计算得到的，而是随机初始化的. 我们会和RNN（或LSTM、GRU）的其他参数一起学习它. 稍后我们会再讨论这个问题.

    在继续之前，我们来看一种简洁的方式来表示RNN、GRU和LSTM计算的函数. 我们在后续内容中会使用这些符号.

    到目前为止，我们已经了解了如何对条件概率分布\(P(y_{t} | y_{1}^{t - 1})\)进行建模. 通俗地说，我们已经知道了如何根据前面的单词生成一个句子. 如果我们想根据图像生成一个句子呢？现在我们关注的是\(P(y_{t} | y_{1}^{t - 1}, I)\)，而不是\(P(y_{t} | y_{1}^{t - 1})\)，其中\(I\)是一幅图像. 注意，\(P(y_{t} | y_{1}^{t - 1}, I)\)同样是一个条件分布.

    之前，我们将\(P(y_{t} | y_{1}^{t - 1})\)建模为： \(\(P(y_{t} | y_{1}^{t - 1}) = P(y_{t} = j | s_{t})\)\)

    其中，\(s_{t}\)是一个捕捉了所有前面单词信息的状态. 现在，我们可以将\(P(y_{t} = j | y_{1}^{t - 1}, I)\)建模为\(P(y_{t} = j | s_{t}, f_{c_{7}}(I))\)，其中\(f c_{7}(I)\)是从图像的\(f c_{7}\)层获得的表示. 有很多方法可以使\(P(y_{t} = j)\)依赖于\(f_{c_{7}}(I)\). 让我们看两种这样的方法.

    选项1¶

    将\(s_{0} = f_{c_{7}}(I)\). 现在，\(s_{0}\)以及所有后续的\(s_{t}\)都依赖于\(f_{c_{7}}(I)\). 因此，我们可以说\(P(y_{t} = j)\)依赖于\(f_{c_{7}}(I)\). 换句话说，我们在计算\(P(y_{t} = j | s_{t}, f_{c_{7}}(I))\).

    选项2¶

    另一种更直接的方法是计算： \(\(s_{t} = \text{RNN}(s_{t - 1}, [x_{t}, f_{c_{7}}(I)])\)\)

    换句话说，我们明确地使用\(f_{c_{7}}(I)\)来计算\(s_{t}\)，进而计算\(P(y_{t} = j)\). 你也可以思考其他使\(P(y_{t} = j)\)依赖于\(f_{c_{7}}\)的方法.

    让我们看看这个架构. 首先使用卷积神经网络（CNN）对图像进行编码，然后使用RNN从编码中解码（生成）一个句子. 这是一种典型的编码器 - 解码器架构，编码器和解码器都使用神经网络. 或者，编码器的输出可以输入到解码器的每一步.

    数据：\(x_{i} = \text{image}_{i}\)，\(y_{i} = \text{caption}_{i}\)，\(i = 1, ..., N\) 模型： - 编码器：\(s_{0} = \text{CNN}(x_{i})\) - 解码器： \(\(s_{t} = \text{RNN}(s_{t - 1}, e(\hat{y}_{t - 1}))\)\) \(\(P(y_{t} | y_{1}^{t - 1}, I) = \text{softmax}(V s_{t} + b)\)\)

    算法：反向传播，梯度下降.

    模块16.3：注意力机制¶

    让我们借助机器翻译任务来理解注意力机制的必要性。编码器仅对句子读取一次并进行编码，在每个时间步，解码器利用这个编码生成一个新单词。但人类翻译句子时是这样的吗？并非如此！

    人类在生成输出中的每个单词时，会尝试仅关注输入中的某些单词。本质上，在每个时间步，我们会针对输入单词生成一个分布，这个分布表明在每个时间步对每个输入单词应给予多少关注。理想情况下，在每个时间步，我们应该只将这些相关信息（即相关单词的编码）输入到解码器中。

    让我们回顾一下目前见到的解码器。我们要么仅在\(s_{0}\)时刻输入一次编码器信息，要么在每个时间步都输入相同的编码器信息。现在假设存在一个“神谕”，它能告诉你在给定的时间步\(t\)应该关注哪些单词。你能想到一种更巧妙的向解码器输入信息的方式吗？

    我们可以对相应单词的表示取加权平均值，然后将其输入到解码器中。例如，在时间步3，我们可以对“ja”和“raha”的表示取加权平均值。直观上，这样做效果会更好，因为我们不会让解码器负载与当前时间步无关的信息（即那些此时不重要的单词信息）。那么，如何将这种直觉转化为模型呢？

    当然，在实际情况中我们并没有这样的“神谕”，机器必须从数据中学习这些信息。为了实现这一点，我们定义一个函数： \(\(e_{jt} = f_{ATT}(s_{t - 1}, c_{j})\)\)

    这个量表示在解码第\(t\)个输出单词时，第\(j\)个输入单词的重要程度（稍后我们会看到\(f_{ATT}\)的确切形式）。我们可以使用softmax函数对这些权重进行归一化： \(\(\alpha_{jt}=\frac{\exp(e_{jt})}{\sum_{j = 1}^{M}\exp(e_{jt})}\)\)

    \(\alpha_{jt}\)表示在生成第\(t\)个输出单词时关注第\(j\)个单词的概率。现在我们尝试学习\(\alpha\)的值，而不是依赖“神谕”来告诉我们\(\alpha\)的值。学习过程总是涉及一些参数，所以让我们为\(\alpha\)定义一个参数化形式。

    从现在开始，我们将解码器RNN在第\(t\)个时间步的状态记为\(s_{t}\)，编码器RNN在第\(j\)个时间步的状态记为\(c_{j}\) 。基于这些新的符号，\(f_{ATT}\)的一种（众多可能选择中的）选择是： \(\(e_{jt} = V_{att}^{T}\tanh(U_{att}s_{t - 1}+W_{att}c_{j})\)\)

    其中，\(V_{att} \in \mathbb{R}^{d}\)，\(U_{att} \in \mathbb{R}^{d×d}\)，\(W_{att} \in \mathbb{R}^{d×d}\)是模型的额外参数。这些参数将与编码器和解码器的其他参数一起学习。

    等一下！如果在训练时能得到真实的\(\alpha\)值，这个模型就很合理了。比如： \(\(\alpha_{tj}^{true}=[0,0,0.5,0.5,0]\)\) \(\(\alpha_{tj}^{pred}=[0.1,0.1,0.35,0.35,0.1]\)\)

    这样我们就可以在之前定义的\(\mathcal{L}(\theta)\)的基础上，额外最小化\(\mathcal{L}(\alpha^{true},\alpha^{pred})\) 。但在实际中，很难得到\(\alpha^{true}\) 。

    例如，在我们的翻译示例中，需要有人手动标注对每个目标单词有贡献的源单词，但获取这样的标注数据非常困难。那么在没有这些数据的情况下，这个模型如何工作呢？

    它之所以有效，是因为这是一种更好的建模选择，是一个更具“智能”的模型。本质上，我们让模型以一种更好（更自然）的方式来处理问题。只要有足够的数据，它应该能够像人类一样学习这些注意力权重，这是我们的期望（而且期望是个好东西）。实际上，这些模型在实践中的表现确实优于普通的编码器 - 解码器模型。

    让我们回顾之前看到的机器翻译模型，并再次回答同样的一组问题（数据、编码器、解码器、损失、训练算法）。

    任务：机器翻译¶

    数据：\(x_{i}=\text{source}_{i}\) ，\(y_{i}=\text{target}_{i}\)，\(i = 1,\cdots,N\) 编码器： \(\(h_{t}=\text{RNN}(h_{t - 1}, x_{t})\)\) \(\(s_{0}=h_{T}\)\) 解码器： \(\(e_{jt}=V_{attn}^{T}\tanh(U_{attn}h_{j}+W_{attn}s_{t})\)\) \(\(\alpha_{jt}=\text{softmax}(e_{jt})\)\) \(\(c_{t}=\sum_{j = 1}^{T}\alpha_{jt}h_{j}\)\) \(\(s_{t}=\text{RNN}(s_{t - 1},[e(\hat{y}_{t - 1}), c_{t}])\)\) \(\(\ell_{t}=\text{softmax}(V s_{t}+b)\)\)

    参数：\(U_{dec}\)、\(V\)、\(W_{dec}\)、\(U_{enc}\)、\(W_{enc}\)、\(b\)、\(U_{attn}\)、\(V_{attn}\)。 损失和算法保持不变。

    模块16.4：图像上的注意力机制¶

    如何为图像建模注意力机制呢？在文本的情况下，我们对输入序列的每个位置（时间步）都有一个表示。但对于图像，我们通常使用全连接层之一的表示，而这个表示不包含任何位置信息。那么注意力机制的输入是什么呢？

    实际上，我们不使用fc7层的表示，而是使用具有空间信息的卷积层的输出。例如，VGGNet的第5个卷积层的输出是一个14×14×512大小的特征图。我们可以将其看作196个位置（每个位置具有512维的表示），模型将在这些位置上学习注意力（这些位置反过来对应于图像中的实际位置）。

    让我们看一些在图像字幕生成任务中，图像注意力机制的示例。（此处原文提供了多组图像及对应描述的示例，主要展示注意力机制在生成描述时聚焦于图像中正确物体的情况，因示例内容以图片形式呈现，难以用文字完整表述，可根据实际需求参考原文图片）

    模块16.5：分层注意力机制¶

    考虑用户（U）和机器人（B）之间的对话： - U：你能推荐一部好电影吗？ - B：当然可以。《金刚狼3：殊死一战》怎么样？ - U：好的，主演是谁？ - B：当然是休·杰克曼。

    对话包含了用户和机器人之间的一系列话语，而每个话语又是一系列单词。因此，我们这里的输入是一个“序列的序列”。你能想到针对这样的序列的编码器吗？

    我们可以考虑一个两层的分层RNN编码器。第一层RNN作用于每个话语中的单词序列，并给出一个表示。此时我们得到了一系列话语表示（图中的红色向量），然后可以用另一个RNN对这个序列进行编码，从而为整个话语序列给出一个单一表示。解码器可以基于这个话语表示生成一个输出序列。

    再看另一个例子，考虑文档分类或摘要任务。一个文档是一系列句子，每个句子又是一系列单词。我们同样可以使用分层RNN对其进行建模。

    数据¶

    \(\{ \text{Document}_{i}, \text{class}_{i} \}_{i = 1}^{N}\)

    单词级（1）编码器¶

    \[h_{ij}^{1}=\text{RNN}(h_{ij - 1}^{1}, w_{ij})$$ $$s_{i}=h_{iT_{i}}^{1}\quad[T\text{是句子}i\text{的长度}]\]

    句子级（2）编码器¶

    \[h_{i}^{2}=\text{RNN}(h_{i - 1}^{2}, s_{i})$$ $$s = h_{K}^{2}\quad[K\text{是句子的数量}]\]

    解码器¶

    \[P(y|\text{document})=\text{softmax}(V s + b)\]

    参数¶

    \(W_{enc}^{1}\)、\(U_{enc}^{1}\)、\(W_{enc}^{2}\)、\(U_{enc}^{2}\)、\(V\)、\(b\)。

    损失¶

    交叉熵。

    算法¶

    采用反向传播的梯度下降法。

    在这样的分层编码器 - 解码器模型中，如何对注意力机制进行建模呢？我们需要在两个层面上应用注意力机制：首先，需要关注句子中重要（最具信息性）的单词；然后，需要关注文档中重要（最具信息性）的句子。让我们看看如何对此进行建模。

    数据¶

    \(\{ \text{Document}_{i}, \text{class}_{i} \}_{i = 1}^{N}\)

    单词级（1）编码器¶

    \[h_{ij}=\text{RNN}(h_{ij - 1}, w_{ij})$$ $$u_{ij}=\tanh(W_{w}h_{ij}+b_{w})$$ $$\alpha_{ij}=\frac{\exp(u_{ij}^{T}u_{w})}{\sum_{t}\exp(u_{it}^{T}u_{w})}$$ $$s_{i}=\sum_{j}\alpha_{ij}h_{ij}\]

    句子级（2）编码器¶

    \[h_{i}=\text{RNN}(h_{i - 1}, s_{i})$$ $$u_{i}=\tanh(W_{s}h_{i}+b_{s})$$ $$\alpha_{i}=\frac{\exp(u_{i}^{T}u_{s})}{\sum_{i}\exp(u_{i}^{T}u_{s})}$$ $$s=\sum_{i}\alpha_{i}h_{i}\]

    解码器¶

    \[P(y|\text{document})=\text{softmax}(V s + b)\]

    参数¶

    \(W_{w}\)、\(W_{s}\)、\(V\)、\(b_{w}\)、\(b_{s}\)、\(b\)、\(u_{w}\)、\(u_{s}\)。

    损失¶

    交叉熵。

    算法¶

    梯度下降和反向传播。
