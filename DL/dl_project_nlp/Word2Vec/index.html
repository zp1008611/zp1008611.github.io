    连续词袋模型（CBOW）¶

    word2vec参数学习详解¶

    Xin Rong ronxin@umich.edu

    摘要¶

    近两年来，Mikolov等人提出的word2vec模型及应用引起了广泛关注。word2vec模型学习到的词向量表示被证明具有语义含义，并在各种自然语言处理任务中非常有用。随着越来越多的研究人员希望尝试word2vec或类似技术，我注意到目前缺乏全面详细解释词嵌入模型参数学习过程的资料，这使得非神经网络专家的研究人员难以理解此类模型的工作机制。

    本笔记提供了word2vec模型参数更新方程的详细推导和解释，包括原始的连续词袋（CBOW）和跳字（Skip-Gram）模型，以及层次Softmax和负采样等高级优化技术。在数学推导的同时，还提供了梯度方程的直观解释。

    在附录中，回顾了神经网络和反向传播的基础知识。我还创建了一个交互式演示wevi，以帮助直观理解模型。

    1 连续词袋模型¶

    1.1 单词上下文¶

    我们从Mikolov等人（2013a）介绍的连续词袋模型（CBOW）的最简单版本开始。我们假设每个上下文只考虑一个词，这意味着模型将根据一个上下文词预测一个目标词，类似于二元语法模型。对于刚接触神经网络的读者，建议先阅读附录A，快速回顾重要概念和术语，然后再继续阅读。

    图1展示了简化上下文定义下的网络模型。在我们的设定中，词汇表大小为V，隐藏层大小为N。相邻层的单元是全连接的。输入是一个独热编码向量，这意味着对于给定的输入上下文词，在V个单元{x₁,⋯,x_V}中只有一个单元为1，其他单元均为0。

    输入层和输出层之间的权重可以用一个V×N矩阵W表示。W的每一行都是输入层相关词的N维向量表示v_w。形式上，W的第i行是v_w^T。给定一个上下文（一个词），假设x_k=1且对于k'≠k，x_k'=0，我们有： [ h = W^T x = W_{(k,·)}^T := v_{w_I}^T ] (1) 这实际上是将W的第k行复制到h中，v_{w_I}是输入词w_I的向量表示。这意味着隐藏层单元的激活函数只是线性的（即直接将输入的加权和传递到下一层）。

    从隐藏层到输出层，有一个不同的权重矩阵W'={w'ij}，这是一个N×V矩阵。利用这些权重，我们可以为词汇表中的每个词计算一个分数u_j： [ u_j = v'^T h ] (2) 其中，v'{w_j}是矩阵W'的第j列。然后，我们可以使用softmax（一种对数线性分类模型）来获得词的后验分布，这是一种多项式分布： [ p(w_j|w_I) = y_j = \frac{\exp(u_j)}{\sum ] (3) 其中，y_j是输出层第j个单元的输出。将（1）和（2）代入（3），我们得到： [ p(w_j|w_I) = \frac{\exp(v'}^V \exp(u_{j'}){w_j}^T v^V \exp(v'})}{\sum_{j'=1{w ] (4)}}^T v_{w_I})

    注意，v_w和v'_w是词w的两种表示。v_w来自输入-隐藏权重矩阵W的行，称为词w的“输入向量”；v'_w来自隐藏-输出矩阵W'的列，称为词w的“输出向量”。在后续分析中，我们将v_w称为词w的“输入向量”，v'_w称为词w的“输出向量”。

    隐藏层到输出层权重的更新方程¶

    现在我们推导该模型的权重更新方程。尽管实际计算不切实际（如下所述），但我们进行推导是为了深入了解这个未应用任何技巧的原始模型。关于反向传播的基础知识，请参见附录A。

    （单个训练样本的）训练目标是关于权重最大化（4）式，即在给定输入上下文词w_I的情况下，观察到实际输出词w_O（在输出层的索引为j）的条件概率。 [ \begin{align} \max p(w_O|w_I) &= \max y_{j} \quad (5) \ &= \max \log y_{j} \quad (6) \ &= u_{j} - \log \sum_{j'=1}^V \exp(u_{j'}) := -E \quad (7) \end{align} ] 其中，E = -log p(w_O|w_I)是我们的损失函数（我们希望最小化E），j*是实际输出词在输出层中的索引。注意，这个损失函数可以理解为两个概率分布之间交叉熵度量的一个特例。

    现在我们推导隐藏层和输出层之间权重的更新方程。对E关于第j个单元的净输入u_j求导，得到： [ \frac{\partial E}{\partial u_j} = y_j - t_j := e_j ] (8) 其中，t_j = 1(j=j*)，即当第j个单元是实际输出词时，t_j=1，否则t_j=0。注意，这个导数只是输出层的预测误差e_j。

    接下来，我们对w'_ij求导，得到隐藏层到输出层权重的梯度： [ \frac{\partial E}{\partial w'_ij} = \frac{\partial E}{\partial u_j} \cdot \frac{\partial u_j}{\partial w'_ij} = e_j \cdot h_i ] (9)

    因此，使用随机梯度下降，我们得到隐藏层到输出层权重的更新方程： [ w'ij^{(new)} = w'_ij^{(old)} - \eta \cdot e_j \cdot h_i ] (10) 或者 [ v' = v'}^{(new){w_j}^{(old)} - \eta \cdot e_j \cdot h \quad \text{对于} \quad j=1,2,\cdots,V ] (11) 其中，η>0是学习率，e_j = y_j - t_j，h_i是隐藏层的第i个单元；v'是w_j的输出向量。注意，这个更新方程意味着我们必须遍历词汇表中的每个词，检查其输出概率y_j，并将y_j与其期望输出t_j（0或1）进行比较。如果y_j>t_j（“高估”），则从v'{w_j}中减去隐藏向量h（即v）的一部分，从而使v'{w_j}远离v；如果y_j<t_j（“低估”，仅当t_j=1时成立，即w_j=w_O），则向v'{w_O}添加一些h，从而使v'。如果y_j非常接近t_j，那么根据更新方程，权重的变化将非常小。再次注意，v_w（输入向量）和v'_w（输出向量）是词w的两种不同向量表示。}更接近v_{w_I

    输入层到隐藏层权重的更新方程¶

    在获得W'的更新方程后，我们现在转向W。我们对E关于隐藏层的输出求导，得到： [ \frac{\partial E}{\partial h_i} = \sum_{j=1}^V \frac{\partial E}{\partial u_j} \cdot \frac{\partial u_j}{\partial h_i} = \sum_{j=1}^V e_j \cdot w'_ij := EH_i ] (12) 其中，h_i是隐藏层第i个单元的输出；u_j在（2）式中定义，是输出层第j个单元的净输入；e_j = y_j - t_j是输出层第j个词的预测误差。EH是一个N维向量，是词汇表中所有词的输出向量乘以其预测误差的加权和。

    接下来，我们应该对E关于W求导。首先，回想一下隐藏层对输入层的值进行线性计算。将（1）式中的向量符号展开，我们得到： [ h_i = \sum_{k=1}^V x_k \cdot w_{ki} ] (13)

    现在，我们可以对E关于W的每个元素求导，得到： [ \frac{\partial E}{\partial w_{ki}} = \frac{\partial E}{\partial h_i} \cdot \frac{\partial h_i}{\partial w_{ki}} = EH_i \cdot x_k ] (14)

    这相当于x和EH的张量积，即： [ \frac{\partial E}{\partial W} = x \otimes EH = x EH^T ] (15) 从中我们得到一个V×N矩阵。由于x中只有一个分量是非零的，因此\frac{\partial E}{\partial W}中只有一行是非零的，该行的值是EH^T，一个N维向量。我们得到W的更新方程为： [ v_{w_I}^{(new)} = v_{w_I}^{(old)} - \eta EH^T ] (16) 其中，v_{w_I}是W的一行，是唯一上下文词的“输入向量”，也是W中导数非零的唯一一行。W的所有其他行在这次迭代后将保持不变，因为它们的导数为零。

    直观地说，由于向量EH是词汇表中所有词的输出向量乘以其预测误差e_j = y_j - t_j的加权和，我们可以将（16）式理解为将词汇表中每个输出向量的一部分添加到上下文词的输入向量中。如果在输出层中，词w_j作为输出词的概率被高估（y_j>t_j），那么上下文词w_I的输入向量将倾向于远离w_j的输出向量；相反，如果w_j作为输出词的概率被低估（y_j<t_j），那么输入向量w_I将倾向于靠近w_j的输出向量；如果w_j的概率被相当准确地预测，那么它对w_I输入向量的移动影响将很小。w_I输入向量的移动由词汇表中所有向量的预测误差决定；预测误差越大，词对上下文词输入向量移动的影响就越显著。

    随着我们通过遍历训练语料库生成的上下文-目标词对来迭代更新模型参数，向量的影响将累积起来。我们可以想象，词w的输出向量被其共现邻居的输入向量“来回拉动”，就好像w的向量和其邻居的向量之间有物理绳子一样。类似地，一个输入向量也可以被视为被许多输出向量拉动。这种解释可以让我们联想到重力，或力导向的图布局。每条想象中的绳子的平衡长度与相关词对的共现强度以及学习率有关。经过多次迭代后，输入和输出向量的相对位置最终将稳定下来。
